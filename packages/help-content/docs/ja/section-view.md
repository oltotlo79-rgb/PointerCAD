# 切って中を見る

立体の**中**がどうなっているかを確かめたいときに使います。画面の上では切れて見えますが、**形はそのままです。** 体積も、保存したファイルも、書き出したファイルも変わりません。

## 出しかた

ツールバーの「表示」に**「断面表示」**のボタンがあります。押すと、**いまの作図面**でその場に切れて見えるようになります。もう一度押すと元に戻ります。

作図面が XY・XZ・YZ のどれでもないとき(自分で作った作業平面や 3D スケッチのとき)は、XY で切って始まります。

## 切る位置を動かす

画面に小さな欄が浮かびます。

| 欄 | できること |
|---|---|
| 切る位置 | 面を前後にずらします。数を打つか、画面のつまみをドラッグします |
| 裏返す | 残る側を反対にします |
| やめる | 断面表示をやめて、元の見た目に戻します |

「切る位置」は式でも書けます(`10*2` や、名前を付けた数値も使えます)。ドラッグしている間もその場で追い直され、待たされることはありません。

右の「プロパティ」にも**「断面表示」**の節が出ます。いまどの面で・どれだけずらして切っているかがそこで読め、入切もそこからできます。

## 切る面を変える

切る面は**いまの作図面**です。別の向きで切りたいときは、いったん断面表示をやめて、ツールバーで作図面を選び直してから押し直してください。

## 「切断」とのちがい

似た名前の道具に**「切断」**(「平面で切る」を見てください)があります。役割はまったく違います。

| | 断面表示 | 切断 |
|---|---|---|
| 形 | 変わらない | 本当に切れて、切り落とした側が無くなる |
| 左の一覧 | 出ない | 「切断1」のように行が増える |
| 保存・書き出し | 影響しない | 切ったあとの形が保存・書き出される |
| 戻しかた | もう一度押す | 取り消し(Ctrl+Z)、または行を消す |

中を確かめたいだけなら断面表示、形として要らない側を落としたいなら切断です。

## 使いかたのこつ

- 中空にした部品の肉厚を目で確かめたいとき、断面表示のまま「測る」で厚みを測れます。
- 断面表示を出したままでも、スケッチも加工もふつうにできます。作業の邪魔はしません。
- 新しい部品を作ったり、別のファイルを開いたりすると、断面表示は自動で切れます。

## うまくいかないとき

| 出る文 | 直し方 |
|---|---|
| 断面の平面を求められません。作図面を選び直してください。 | ツールバーで XY・XZ・YZ のどれかを選んでから押し直します |

**切っても何も見えない**ときは、切る位置が立体から外れています。「切る位置」を 0 に戻すか、「裏返す」を押してみてください。
