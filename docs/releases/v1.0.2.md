# PointerCAD v1.0.2 リリースノート

*バージョン: v1.0.2(v1.0.1の不具合修正版)。v1.0.0・v1.0.1と同じく、デスクトップ版(Windows・Linux)を先に公開し、Web版は後日あらためて公開します。デスクトップ版の配布物には発行元の署名がありません(未署名)。詳しくは「配布物について(未署名)」の節と、[デスクトップ版の導入・更新・削除](../../packages/help-content/docs/ja/desktop-install.md)を参照してください。*

## PointerCADについて

PointerCADは、「前の点から右へ40mm」「板厚の2倍の位置」のように、作りたい形の決め方をそのまま入力できる3D CADです。座標・相対距離・角度・数式を使って描き、マウスで形を確かめながら立体や加工を加えられます。Windows・Linuxのデスクトップ版と、ブラウザで使えるWeb版を用意しています。

デスクトップ版を、無料で使えるオープンソースソフトウェア(ライセンス: Apache-2.0)として公開しています。

## 新しくなったこと

### ポータブル版の終了後の片付けが動くようになった

Windowsポータブル版を閉じると、起動時に一時フォルダーへ取り出した内容を自動で削除するようになりました(通常30秒以内)。他に起動中のポータブル版があるときは、その分は消しません。強制終了したときや、取り出した場所に別のファイルを置いたときは残るので、その場合は自分で削除してください。[デスクトップ版の導入・更新・削除](../../packages/help-content/docs/ja/desktop-install.md)

### 遅いパソコンでも計算が時間切れになりにくくなった

数式や関数の計算の待ち時間の上限を、使っているパソコンのその時の速さに合わせて最大4倍まで伸ばすようにしました。普段どおりの速さのパソコンでは、今までと同じ待ち時間のままです。中止の操作はいつでもすぐに効きます。[計算の準備と取消](../../packages/help-content/docs/ja/math-input.md#計算の準備と取消)

### 数式の窓の「取消」を開いた直後でも確実に押せるようにした

数式を入力する窓を開いてすぐ「取消」を押すと、準備中と準備が終わった後でボタンの位置が変わり、押し逃すことがありました。準備の前後で同じ位置の同じボタンから取り消せるようにしました。

## 直したこと

- 数式の「比べる幅」で、合同・相似のように「はい」「いいえ」で答える結果のとき、「係数を作る」が押せない理由が「値が決まっていない」という誤った説明になっていました。「この結果は「はい」「いいえ」なので、係数を作れません。」という正しい説明に直しました。
- 説明書に画像を5件足しました。

## 主な機能

v1.0.0・v1.0.1から使える機能(座標とマウスで描く、名前付きの数式で寸法を管理する、関数で曲線・曲面を定義して設計に使う、立体を作る・加工する、組み立てる、図面を作る、板金を設計する、形を調べる・強度を検討する、作図を自動化する、保存・データの受け渡し)は、v1.0.2でもそのまま使えます。内容は[v1.0.0のリリースノート](v1.0.0.md)・[v1.0.1のリリースノート](v1.0.1.md)と、READMEの「できること」の表を参照してください。

## ヘルプと取扱説明書

アプリ内でF1キーからヘルプを開き、検索や章ごとの案内から操作を探せます。「初めての作図」など目的別のヘルプも用意しています。配布物には取扱説明書(HTML・PDF、全7分冊)を同梱しています。説明書の本文と画像はv1.0.2の画面に合わせて作り直しています。

## 対応環境

- デスクトップ版(このリリースでの入手先): Windows 10/11(x64)、Linux(x64、AppImageで配布)
- Web版(後日あらためて公開): 最新のChrome・Edge・Firefoxで、ダウンロード不要でブラウザから使えます

デスクトップ版とWeb版は同じ機能を持ちます(保存方法などプラットフォーム固有の部分を除く)。Web版は公開が決まり次第、このリリースノートとREADMEにリンクを追記します。

## 配布物について(未署名)

このリリースのWindows・Linux向け配布物には、発行元の署名がありません(未署名)。ダウンロード・実行時にOSから発行元を確認できない旨の警告(Windowsでは「Windows によって PC が保護されました」というSmartScreenの画面)が表示される場合があります。入手元が本プロジェクトのGitHubリリースページであることを確認したうえで、実行を続けるかどうかを判断してください。

配布ページには各ファイルのSHA-256の値を[SHA256SUMS](https://github.com/oltotlo79-rgb/PointerCAD/releases/download/v1.0.2/SHA256SUMS)として添えています。ダウンロードしたファイルが配布時点のものと変わっていないか照合できます。導入・更新・削除の手順、警告の進め方、ハッシュの照合方法は[デスクトップ版の導入・更新・削除](../../packages/help-content/docs/ja/desktop-install.md)にまとめています。

## 入手方法

公開済みの[v1.0.2リリース](https://github.com/oltotlo79-rgb/PointerCAD/releases/tag/v1.0.2)には、`PointerCAD-1.0.2-windows-x64-setup.exe`、`PointerCAD-1.0.2-windows-x64-portable.exe`、`PointerCAD-1.0.2-linux-x64.AppImage`と取扱説明書のPDF全7巻があります。各ファイルのダウンロード先はREADMEの「入手方法・取扱説明書」の表を参照してください。Web版へのリンクは、Web版の公開が決まり次第、この文書とREADMEに追記します。

v1.0.1から更新するときは、インストーラー版は新しいインストーラーを実行すると今の導入先へ上書きして更新します。ポータブル版・AppImageは、アプリを終了してから新しいファイルに置き換えて使います。設定と保存した文書はそのまま使えます。
