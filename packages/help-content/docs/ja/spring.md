# ばねを作る

要件の文書では「スプリング」と呼びますが、画面では「ばね」と出ます。

コイル状のばね(コイルばね)を、立体として新しく作ります。押し出しや回転と同じく、もとになる立体を必要としません。

## 手順

1. 点の道具で、ばねの**始点**にする点を 1 つかきます。
2. 「選択」の道具のまま、その点をクリックして選びます。
3. ツールバーの「ソリッド」区画で「作る」を押して一覧を開き、「ばね」を押します。
4. 「ばねの形を決める」という入力欄が出るので、「コイル径」と「線径」を入れて Enter を押します。
5. 続けて「ばねの長さを決める」が出るので、「ピッチ」と「巻数」を入れて Enter を押すと、ばねができます。

始点にする点を選ぶまでは「ばね」のボタンは薄いままで押せません。

## 軸(伸びる向き)

入力欄(または右の「プロパティ」)の「軸」で、ばねが伸びる向きを X・Y・Z のいずれか、またはスケッチでかいた線分から選べます。軸から少し傾けたいときは、ばねを作ったあとに右の「プロパティ」で「傾き」と「傾ける向き」を数値で入れます。

## 全長・ピッチ・巻数は、2つ決めれば残りが決まる

ばねの**全長**(らせん部分の長さ)・**ピッチ**(1巻きごとに軸方向へ進む距離)・**巻数**は、「全長 = ピッチ × 巻数」の関係にあります。3つのうち2つを入れると、残り1つは自動で計算され、「求める値」で選んだ欄に読み取り専用で表示されます。

右の「プロパティ」で「求める値」を「全長」から「ピッチ」や「巻数」に切り替えると、新しく計算対象になった欄の数字がその場で入れ替わります。

全長は、線の太さ(線径)を含まない、らせんそのものの長さです。

## 巻き方向

「巻き方向」で、右巻き・左巻きを選べます。見た目が左右反転するだけで、体積は変わりません。

## 端の形

ばねの両端は、水平に切りそろえず斜めに切れた形になります(座巻きは作りません)。

## うまくいかないとき

「ばね」を押しても何も起きないとき、または作ったものの一覧に理由が出たときは、次を確かめてください。

| 出る文 | 直し方 |
|---|---|
| ばねの始点にする点が選ばれていません。 | 始点にする点をクリックしてから、もう一度「ばね」を押します |
| 線径はコイル径より小さくしてください。 | 線径の数字を小さくします |
| ピッチは線径より大きくしてください。隣どうしの線がぶつかります。 | ピッチを大きくするか、線径を小さくします |
| 巻数は 200 以下にしてください。 | 巻数の数字を見直します |

## 巻数が多いと計算に時間がかかる

巻数を増やすほど、形の計算に時間がかかります。数百巻きに近づけると、ほかの道具より待たされることがあります。
