## 0. 依頼と範囲

2026-09-11の利用者指示「任意の2点から方向・角度・長さで線分を引き、交点に点を自動作成し、分割後に曲げたり不要部分を消せるか調査。なければ追加」を正とする。FR-107の吸着・FR-301〜307の入力・FR-322のトリム・FR-505のUndoを接続する追加要求である。

### 0.a 決定

- 原タスクID **ADD-1** の1件として扱う。検査ケースや変更ファイルを完了タスクへ数えない。従来の552件に1件を追加して総数553件とし、将来フェーズ見積115件は引き続き含める。
- 線分の終点入力に「交点でつなぐ」を既定オンで配置する。マウス・数値ポップアップ・コマンドラインの確定を共通経路へ通す。オフなら独立した線のまま扱える。
- 交点は普通の点フィーチャーとして作り、名前を「交点1」などにする。外側の始点・終点の入力は「線分1 始点」「線分1 終点」へ式のまま保持し、分割線はその点を参照する。共有点の移動で折れ曲がり、各区間をDelete/トリムで消せる。
- 交点は分割確定時の実座標で保持する。以降も元の2直線の交点であるという拘束は付けない（点を動かして曲げる目的と両立しないため）。既存の拘束の意味を部分線分へ変更しない。対応できない拘束付きの線は確定を断り、拘束解除またはオフで進める理由を表示する。
- 新しい保存形式を導入せず既存の点・線・面の形式を使う。最後の区間に元の線ID/終点を残し、始点参照と面/オフセット/複写の全境界は分割後の参照へ付け替える。全体を1回のUndoとして適用する。

## 1. 完了条件（ADD-1）

| 項目 | 受入条件 |
|---|---|
| 入力 | 任意始点と相対/極座標の角度・長さ・式から交差する線を作れる |
| 自動接続 | 交差2本は4区間、T字は3区間、複数交点は全区間を作る。同位置の交点を増殖させない |
| 除外 | 構築線・平行・重複・範囲外・実空間で離れた3D線を誤分割しない |
| 編集 | 共有点の数値編集と2Dドラッグで接続線が追従する。外側の式は残る。3Dでは既存の座標編集を使う |
| 不要区間 | トリムの赤い予告と削除区間が一致する。Deleteは選んだ区間だけを消す |
| 履歴・互換 | 分割作成・移動・削除はそれぞれUndo1回、Redo可能。既存面と参照を維持。保存して再開しても編集可能 |
| UI/説明 | 実画面でつまみ・交点の名前・編集・削除・取消を検査し、実画面画像をヘルプと説明書の共通章へ追加する |
