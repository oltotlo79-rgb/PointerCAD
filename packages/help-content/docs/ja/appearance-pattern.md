# 柄を選ぶ

色や材質に加えて、面へ縞模様や網目などの模様(柄)を付けられます。

## 柄を選ぶ(3 種)

プロパティの「外観」の節にある「柄」で、次から選びます。

| 柄 | 見え方 |
|---|---|
| なし | 模様を付けません |
| エキスパンドメタル | 網目模様(材質から「エキスパンドメタル」を選ぶと自動で付きます) |
| 縞鋼板 | 縞模様(材質から「縞鋼板」を選ぶと自動で付きます) |
| 木目 | 木の年輪のような模様(材質から「木材」を選ぶと自動で付きます) |

## 模様の大きさを数値で決める

柄を選ぶと「模様の大きさ」の欄が出ます。ミリメートル単位の数値(式も打てます)で、模様の繰り返しの間隔を決めます。数値を小さくするほど模様は細かく、大きくするほど粗くなります。

## 木材の樹種

柄を「木目」にすると、樹種を選べるようになります。ヒノキ・スギ・ナラ・ウォールナット・チーク・メープルの 6 種類から選ぶと、地の色と木目の色がまとめて変わります。

## エキスパンドメタルは穴が空いて見えるが、形に穴は開かない

エキスパンドメタルの柄を付けた面は、網目の隙間から向こう側が見えます。ただし、これは見た目だけの模様であり、立体そのものに穴を開けているわけではありません。体積や、穴の道具で作った本物の穴とは違うので、その面を使って寸法を測るときや、そこへさらに加工を加えるときは、実際には穴が空いていないことに注意してください。

## うまくいかないとき

うまくいかない理由や、出る文の一覧は色・材質と共通です。「色と材質を選ぶ」のヘルプを見てください。
