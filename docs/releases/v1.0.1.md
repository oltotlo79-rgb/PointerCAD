# PointerCAD v1.0.1 リリースノート

*バージョン: v1.0.1(v1.0.0の操作性と説明の改良版)。v1.0.0と同じく、デスクトップ版(Windows・Linux)を先に公開し、Web版は後日あらためて公開します。デスクトップ版の配布物には発行元の署名がありません(未署名)。詳しくは「配布物について(未署名)」の節と、[デスクトップ版の導入・更新・削除](../../packages/help-content/docs/ja/desktop-install.md)を参照してください。*

## PointerCADについて

PointerCADは、「前の点から右へ40mm」「板厚の2倍の位置」のように、作りたい形の決め方をそのまま入力できる3D CADです。座標・相対距離・角度・数式を使って描き、マウスで形を確かめながら立体や加工を加えられます。Windows・Linuxのデスクトップ版と、ブラウザで使えるWeb版を用意しています。

無料で使えるオープンソースソフトウェア(ライセンス: Apache-2.0)として公開します。

## 新しくなったこと

### 右ドラッグで画面を平行移動する

3D表示をマウスの右ボタンで引っ張ると、画面を引っ張るように表示の中心を動かせます。透視投影でも平行投影でも使え、4分割の表示ではその区画だけが動きます。右ボタンを動かさずに押して離したときは、今までどおり道具の一覧(右クリックの8方向メニュー)が開きます。部品や組立の形、作図途中の入力は変わりません。[画面を回す・動かす・拡大する](../../packages/help-content/docs/ja/viewport.md)

### 起動してすぐ出る起動の画面と、軽くなった起動

アプリを開くとすぐに製品名の入った起動の画面が出て、3D表示の準備ができると切り替わります。必要になるまで読み込まない部分を増やし、起動の時に読み込む量を減らしました。準備ができた時の下の帯の案内には、画面の回転・平行移動・拡大縮小と右クリックの操作を載せています。

### 入力の窓を見出しのドラッグで動かす

点・線分の座標、加工の寸法、数式などを入れる窓は、上の見出しをドラッグして動かせます。見出しの点の印がつまみで、指やペンでも動かせます。動かしている間も入力中の値と焦点は保たれます。窓や画面の大きさが変わったときは、見出しと入力欄が画面内に収まるように位置を調整します。[入力の窓を動かす](../../packages/help-content/docs/ja/numeric-input.md#入力の窓を動かす)

### 向きを示す立方体の見た目を新しくした

画面の右上の立方体の角を面取りし、陰影を付けました。面・辺・角にカーソルを重ねると切り替わる部分に色と輪郭が付き、押している間は色が濃くなります。立方体の下に方位のリング、外側に赤のX・緑のY・青のZの目印を置き、左上の家のボタンで前・上・右の3面が見える最初の向きへ戻せます。大きさと配色は「設定」の拡大率とテーマに合わせて変わります。[画面を回す・動かす・拡大する](../../packages/help-content/docs/ja/viewport.md)

### 計算中も次の操作が分かる

形を計算している間も、下の帯に選んだ道具の案内が残ります。案内の隣の回る印と「計算中」の表示で計算していることが分かり、長い計算では進み具合の細い帯と中止のボタンも出ます。[画面の見方](../../packages/help-content/docs/ja/tutorial.md#画面の見方)

### 使えない操作の理由をそろえて表示する

使えない操作を選んだときは、理由と次にすることを下の帯に同じ形で表示します。実行できなかった道具で「最近使った道具」を書き換えないようにしました。固定した部品では「固定を解除する」と表示し、次にできる操作が分かるようにしました。

### 図面の用紙の設定に式を使える

用紙の縮尺・縮尺の候補・文字高さ・表題欄の幅の比率に、`1/2`や`7/2`のような式を入力できます。図面を保存して読み直したときや、保存したひな形から作ったときも、入力した式のまま編集できます。誤った式はその欄に理由を表示し、設定の一部だけを変えることはありません。[用紙の設定](../../packages/help-content/docs/ja/drawing-scale.md#用紙の設定)

## 直したこと

- 測る: 密度に0・負の数・誤った値を入れたときや計算待ちのときに、質量・慣性の値を出さないようにしました。取り消した測定の結果が後から戻ることがなくなりました。表示の単位を切り替えると、3D表示の札の文字も切り替わります。初めての測定の途中でもEscで取り消せます。
- 質量特性: 長い値が並ぶと見出しの文字が隠れることがある表示を直しました。
- 3Dプリント向けの点検: 肉厚と角度の基準に式を使え、結果にどの基準を使ったかを表示します。
- 角丸め・面取り: 面を張った後に角を丸めたり面取りしたりしても、面の境界を自動でつなぎ直します。「元に戻す」1回で線と面を一緒に戻せます。
- 部品と組立のメニュー: 上下の矢印キーやHome・Endで項目を選べるようにし、Escで元の行のボタンへ戻ります。
- 名前の変更: 日本語入力の変換をEnterで確定しただけで名前が保存されてしまう問題を直しました。
- 元に戻す・やり直し: 部品・組立・図面で同じCtrlのキー操作にそろえ、文字の入力中は入力欄の編集を優先します。
- 説明書・ヘルプ: 加工の道具の説明を、対象を選ぶ前でも道具を押せる今の動きに合わせ、外ねじの作り方などを足しました。選択セットの元に戻す操作、タイムラインのクリックとドラッグ、配布元の案内なども今の動きに合わせました。
- 説明書の画像: 全ての画像(227枚)を、v1.0.1の画面で撮り直しました。

## 主な機能

v1.0.0から使える機能(座標とマウスで描く、名前付きの数式で寸法を管理する、関数で曲線・曲面を定義して設計に使う、立体を作る・加工する、組み立てる、図面を作る、板金を設計する、形を調べる・強度を検討する、作図を自動化する、保存・データの受け渡し)は、v1.0.1でもそのまま使えます。内容は[v1.0.0のリリースノート](v1.0.0.md)と、READMEの「できること」の表を参照してください。

## ヘルプと取扱説明書

アプリ内でF1キーからヘルプを開き、検索や章ごとの案内から操作を探せます。「初めての作図」など目的別のヘルプも用意しています。配布物には取扱説明書(HTML・PDF、全7分冊)を同梱します。説明書の本文と画像はv1.0.1の画面に合わせて作り直しています。

## 対応環境

- デスクトップ版(このリリースでの入手先): Windows 10/11(x64)、Linux(x64、AppImageで配布)
- Web版(後日あらためて公開): 最新のChrome・Edge・Firefoxで、ダウンロード不要でブラウザから使えます

デスクトップ版とWeb版は同じ機能を持ちます(保存方法などプラットフォーム固有の部分を除く)。Web版は公開が決まり次第、このリリースノートとREADMEにリンクを追記します。

## 配布物について(未署名)

このリリースのWindows・Linux向け配布物には、発行元の署名がありません(未署名)。ダウンロード・実行時にOSから発行元を確認できない旨の警告(Windowsでは「Windows によって PC が保護されました」というSmartScreenの画面)が表示される場合があります。入手元が本プロジェクトのGitHubリリースページであることを確認したうえで、実行を続けるかどうかを判断してください。

配布ページには各ファイルのSHA-256の値を`SHA256SUMS`として添え、ダウンロードしたファイルが配布時点のものと変わっていないか照合できるようにします。導入・更新・削除の手順、警告の進め方、ハッシュの照合方法は[デスクトップ版の導入・更新・削除](../../packages/help-content/docs/ja/desktop-install.md)にまとめています。

## 既知の制限

- ポータブル版の終了後に一時フォルダーへ展開物が残ります(v1.0.2で対応予定)。ポータブル版は起動のたびに実行に必要な内容をWindowsの一時フォルダーへ取り出します。v1.0.1では終了後の片付けを行わないため、v1.0.0と同じく取り出した内容が一時フォルダー(`%TEMP%`)に残ります。不要になった場合は、PointerCADを終了してから、Windowsの設定の「一時ファイル」の削除などで消せます。設定や保存した文書は一時フォルダーとは別に管理しているため、消しても残ります。
- Web版は今回のデスクトップ版公開の時点では未公開です(後日あらためて公開)。
- デスクトップ版の配布物には発行元の署名がありません(未署名)。詳しくは「配布物について(未署名)」の節を参照してください。

## 入手方法

配布物(Windowsインストーラー・Windowsポータブル版・Linux AppImage)と取扱説明書(PDF全7巻)は、GitHubのReleaseページから入手できます。ファイル名とダウンロード先はREADMEの「入手方法・取扱説明書」の表を参照してください。Web版へのリンクは、Web版の公開が決まり次第、この文書とREADMEに追記します。

v1.0.0から更新するときは、インストーラー版は新しいインストーラーを実行すると今の導入先へ上書きして更新します。ポータブル版・AppImageは、アプリを終了してから新しいファイルに置き換えて使います。設定と保存した文書はそのまま使えます。
