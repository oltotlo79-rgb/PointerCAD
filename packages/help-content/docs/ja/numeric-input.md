# 数値と式の入れ方

長さや角度を入れる欄では、数字のかわりに**式**を書けます。書いた式はそのまま残るので、後から開いて直せます。

## 入力の窓を動かす

点や線分の座標、加工の寸法などを入れる窓は、上の見出しをドラッグして動かせます。見出しの点の印がつまみです。マウスの左ボタンのほか、指やペンでもつかんで動かせます。入力欄やボタンを押しても窓は動きません。

![線分の終点の窓に座標を入れたまま、見出しの点の印をつかんで左上へ動かした後の窓。入れた値（Yは式で、下に「= 20」）と、Yの欄の焦点がそのまま残る](images/numeric-input-drag-detail.png)

数式、関数、組み立て、図面の注記などの浮いた入力の窓も、同じように見出しから動かせます。窓が大きくなったときや画面を小さくしたときは、見出しと入力欄が画面内に収まるように位置が調整されます。高さが足りないときは窓の中をスクロールできます。

その場の数値入力では、移動しても入力中の欄に焦点が残り、Tab で欄を移る、Enter で決める、Esc でやめる操作はそのまま使えます。移動した位置は窓を開いている間だけ保ち、閉じてから開き直すと、クリックした場所の近くなど元の位置に戻ります。

## 使える書き方

| 書きたいこと | 書き方 | 例 |
|---|---|---|
| 足す・引く・かける・わる | `+` `-` `*` `/` | `10+5` `100/3` |
| かっこ | `(` `)` | `(10+5)*2` |
| 累乗 | `^` | `2^10` |
| 平方根 | `sqrt( )` または `√` | `sqrt(2)` `√2` |
| 立方根 | `cbrt( )` | `cbrt(8)` |
| n 乗根 | `root(数, n)` | `root(27,3)` |
| 絶対値 | `abs( )` | `abs(0-5)` |
| 分数 | `/` | `3/4` |
| 円周率 | `pi` または `π` | `pi*10` |
| 自然対数の底 | `e` | `e^2` |

全角のまま(`１＋２`、`（`、`×`、`÷`)打っても、そのまま計算できます。

## 角度の書き方

角度の欄は**度**で読みます。`90` と書けば 90 度です。ラジアンで書きたいときは `rad( )` で包みます。`rad(pi/2)` は 90 度と同じです。

## 欄の使い方

入力欄は、道具を選ぶと 3D の表示の中央に浮かんで出ます。表示の中の置きたい場所をクリックすると、その位置の座標が欄に入り、欄もクリックした場所の近くへ移ります。出ている間も画面を回したり拡大したりできます。

| やりたいこと | 操作 |
|---|---|
| 次の欄へ移る | Tab キー(最後の欄で押すと先頭へ戻ります) |
| 前の欄へ戻る | Shift + Tab キー |
| そのまま決める | Enter キー、または「決定」 |
| やめる | Esc キー、または「取消」 |
| 位置の決め方を変える | 「絶対」「相対」「極」を押す(Alt+1、Alt+2、Alt+3) |

欄には最初から値が入っています。そのままでよければ Enter を押すだけで決まります。欄へ移ると中の文字がすべて選ばれるので、打ち始めれば上書きになります。

欄の右側の `mm` や `°` は、その欄が何の単位で読まれるかを示します。

## 日本語の変換中と文字の編集

部品の数値入力、組立の合致入力、図面の文字注記では、日本語の変換中に押した Enter と Esc は変換の操作に使います。この段階では形や注記を確定せず、入力の窓も閉じません。変換が終わってから Enter を押すと、部品の点や組立の合致を決められます。

図面の文章欄では、変換後の Enter は改行です。注記を決めるには「{{ui:drawing.action.apply}}」を押します。Esc はまだ決めていない入力をやめる操作で、すでに作った形や注記を取り除きません。

Tab と Shift + Tab で入力先を移せます。文字の欄での Delete と Backspace は文字を消し、Ctrl/Cmd + Z は文字の編集を元に戻します。形を元に戻すときは入力を終え、作図画面へ焦点を移してから操作してください。

## 正しく書けているかの見かた

式が正しければ、欄の下に計算した値が `= 15` のように薄く出ます。正しくないときは欄と文字が赤くなり、下に理由(たとえば「0 で割ることはできません。」)が出ます。理由が出ている間は決めても作られず、直すところへ印が移ります。

入力中の欄にパラメータ名や `in` などの単位があれば、決める前に、欄の下へ「入力中の式の情報」が出ます。

- 「欄の単位」: その欄が読む単位(`mm`・`°`、表示を inch にした長さの欄は `in`)です。
- 「式に書かれた単位」: `1in*2` のように式の中へ書いた単位です。
- 「参照するパラメータ」: 式の中で使った名前を、書いた順に「名前 (何文字目)：元の値」の形で並べます。`板厚*2` なら「板厚 (1文字目)：3 mm」です。同じ名前を2回書くと、それぞれの位置が分かります。角度のパラメータは `30°` のように `°` が付きます。
- 「形・数式での使用箇所」: この部品の形や数学式の中で、その名前を使っている式の数です。押し出しの距離だけが `板厚 * 2` なら、`板厚` は 1 です。
- 「影響するフィーチャー数」: 書いた名前を、直接、または別のパラメータを通して間接に使っているフィーチャーの数です(同じフィーチャーは1つと数えます)。`板厚` を使う `厚み = 板厚*2` を押し出しが使っていれば、`板厚` の影響は押し出し1つです。名前が循環している、名前がパラメータにない、数えられなかった、のいずれかのときだけ「未確認」と出て、推測した数は出しません。この数はこの部品の中だけです。組立や図面の中で、この部品を使う別の文書への影響はここには含まれません。

たとえば板厚を 3 mm にしてあるとき、距離の欄へ `板厚*2` と書くと、欄の下に `= 6`、情報の中に「板厚 (1文字目)：3 mm」と使用箇所の数が、Enter を押す前に出ます。

書き方が正しくないときは、欄の下の赤い理由に加えて「入力中の誤りの位置」が「3文字目」のように出て、式の中の該当の文字に印が付きます。たとえば `1.5ft` は 4 文字目の `f`、`10kg` は 3 文字目の `k` に印が付きます。`1+` のように式の末尾で足りないときは、末尾に `│` の印が出ます。長さの欄で `1in 3` のように単位のあとへ余計な文字を書いたときも、その文字の位置を示します。

この案内を見ても、書いた式は1文字も変わらず、形は変わらず、元に戻す履歴も増えません。画面下の単位ボタンで mm と inch を切り替えても、欄に書いた式はそのままで、読む単位と表示だけが変わります。Esc で入力をやめると案内も消え、次に開いた欄へは前の案内を引き継ぎません。

## 位置の決め方

| 決め方 | 意味 | 入れるもの |
|---|---|---|
| 絶対 | 原点からの位置 | X、Y、Z |
| 相対 | 基準の点からのずれ | ΔX、ΔY、ΔZ |
| 極 | 基準の点からの距離と向き | 距離、角度、仰角 |

「相対」と「極」の基準は、直前に作った点です。決め方を変えると入れるものの意味が変わるので、欄は最初の値に戻ります。

## 続けてかくとき

続けてかく設定のときは、決めたあとも入力欄が開いたままになり、直前の点を基準にして次の入力へ進みます。やめるときは Esc キーを押します。
