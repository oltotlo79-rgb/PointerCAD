# なめらかな曲線をかく(スプライン)

画面の上の「作図」から「スプライン」を選ぶと、点を並べて、その点にそったなめらかな曲線をかけます。

## かき方

1. 「スプライン」を選びます。
2. 曲線を通したい場所をクリックして Enter を押します。これを置きたい点の数だけくり返します。置いた点はビューポートに順に現れます。
3. 置き終えたら、入力欄の**「点を置き終える」**を押します。
4. 「点の使い方」と「閉じる」を選んで Enter を押すと、曲線ができます。

点は開いた曲線で 2 つ以上、閉じた曲線で 3 つ以上、いちどにかける上限は 100 個です。足りないときや多すぎるときは、画面の下の帯に理由が出て、曲線はできません。

置いた点を間違えたときは、Esc を押すとその曲線をやめて最初からかき直せます。

## 点の使い方

| 選び方 | 曲線と点の関係 |
|---|---|
| 通過点 | 置いた点を必ず通ります。手がきの線をなぞるときに向いています |
| 制御点 | 置いた点が曲線を引っぱります。曲線は点を通らず、外側から引かれたようになだらかになります |

初期は「通過点」です。

「通過点」では、同じ場所に点を重ねて置くと曲線の形が決まりません。このときは帯に理由が出るので、点をずらしてかき直してください。「制御点」では重なっていてもかまいません。

## 閉じる

「閉じる」を入にすると、最後の点から最初の点へなめらかにつながり、輪になります。**輪にするために最初の点をもう一度置く必要はありません。**

閉じた曲線はそのまま面の囲みに使えるので、「面」の道具でクリックして Enter を押せば中が塗られ、押し出して立体にできます。

## 実体にしない曲線

「点の使い方」を選ぶ画面には「構築線にする」というつまみもあります。入にすると、形を決めるための補助の曲線になり、面の材料にはなりません。

## 直したいとき

かいた曲線は、左の一覧から選ぶと、右のプロパティで各点の座標を数や式で直せます。取り消したいときは、上の「元に戻す」を押すと曲線がまるごと消えます。
