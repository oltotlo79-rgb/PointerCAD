# 5. 禁止事項

- **作業担当はブラウザの窓・Electronアプリ・開発サーバー(`vite dev` 等)を起動しない。** 利用者の画面に予期しない窓を出さないため。ヘッドレスで完結するテスト実行(Vitest、Playwrightのheadlessモード)は可。headedモードのブラウザ自動化は統括の承認がある場合だけ使う。アプリの起動・終了は統括が行う(`rules/01-役割と委譲.md` §1)。
- **Electronアプリ・開発サーバーを二重起動しない。** 起動前に該当プロセスと待受ポートを確認し、残っていれば閉じない原因を記録して完全に終了させてから起動する。
- **`package.json` の依存関係(dependencies / devDependencies)、`pnpm-lock.yaml`、`pnpm-workspace.yaml`、vendorされたバイナリ(OCCT WASM等)を無断で変更しない。** 依存の追加・更新・削除が必要なら作業を止め、理由と差分案を統括へ提出する。統括が差分を読んで採否を決める。幾何カーネル(opencascade.js)のバージョンは検証付きでのみ更新する(要件 `docs/requirements.md` §6.1)。
- **ビルドやテストの実行中プロセスを強制終了しない。** 成果物を生成中の処理は終了を待ってから停止する。途中終了は成果物の破損やロックファイルの残留を招くため。
- **テストの期待値を安易に書き換えて赤を消さない。** 性能テストの上限値を緩めることも禁止する。不具合を直さず合格に見せかけることになるため。
- **警告・型エラーを封じて黙らせない。** `eslint-disable`、`@ts-ignore`、`@ts-expect-error`、`any` への型変更、`as unknown as` による強制変換で検査をすり抜けることを禁止し、原因を修正する。`tsconfig` のstrict系フラグを緩めることも禁止する。やむを得ず抑止が必要な場合は理由を統括へ提出し、承認を得てから理由コメント付きで行う。
- **統括は `pnpm` / `npm` / `npx` / `yarn` を直接実行しない。** 検査は `scripts/check.ps1`、それ以外は作業担当へ委譲する(`.claude/settings.json` のフックが拒否する)。
