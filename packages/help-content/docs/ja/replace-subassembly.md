# 部品を差し替える・組を置く

部品を差し替えるときは、左の一覧で部品を1つ選び、上の **組む** から **{{ui:assembly.tool.replacePart}}** を選びます。新しい `.pcad` ファイルを選ぶと、既存の合致とジョイントをできるだけ同じ対象へ選び直します。

選び直せない対象がある場合だけ、件数とともに確認が出ます。**差し替える**で確定し、**取り消す**またはEscで元のまま閉じます。すべて選び直せた場合は確認を増やさず、そのまま確定します。

別のアセンブリをまとめて置くときは **{{ui:assembly.tool.placeSubAssembly}}** を選び、`.pcada` ファイルを開きます。置いた組は左の一覧で畳んだり開いたりできます。自分自身を含む組や深すぎる入れ子は、理由を表示して置きません。

![空のアセンブリへ2部品の組を「サブアセンブリを置く」で置いた直後のモデルブラウザ。「部品」に組「2部品:1」が並び、中に箱:1・箱:2](images/replace-subassembly-placed-detail.png)

どちらの確定も「元に戻す」1回で操作前へ戻せます。

## うまくいかないとき

- **このアセンブリは自分自身を含んでいます。** … 組を置くときに、いま開いているアセンブリ自身(またはそれを含む組)を選ぶと出ます。別のファイルを選んでください。
- **組の入れ子が深すぎます(8 段まで)。** … 組の中に組を重ねる深さが8段を超えるファイルを選ぶと出ます。どちらの場合も組は置かれません。
- 差し替えで選び直せなかった合致・ジョイントは削除されず、古い対象を指したまま残ります。差し替えた後にその行に未解決の印が出るので、対象を選び直してください。

差し替えた部品やまとめて置いた組は、他の部品と同じように組み立てに保存され、開き直しても保たれます。

## 同じ元部品を取り込み直す

元の部品で式や寸法を変更して `.pcad` を保存したら、組の左の一覧でその部品の「⋮」を開き、**{{ui:assembly.refresh.action}}** を選びます。同じ部品文書の保存済みファイルを選んでください。同じ元部品を使うすべての配置が更新されます。

この操作は配置と合致・ジョイントの保存済み参照を保持します。上の **{{ui:assembly.tool.replacePart}}** は別の部品への変更と対象の選び直しに使います。取り込み直しで対象が消えたり一意に決まらなくなった場合、参照を自動で置き換えず、未解決の理由を表示します。

取り込み直しは「元に戻す」1回で戻せます。同じ内容を選んだ場合は変更や履歴を増やしません。ファイルの変更を背景で監視する機能ではなく、保存後にこの操作を実行します。

新規作成した部品には、その文書の系列を区別するIDが付きます。通常の保存・別名保存・開き直しではIDを変えません。このIDはファイルの真正性を保証するものではありません。

古い部品では別の文書も同じIDを持つ場合があるため、内容が変わったファイルを選ぶと **{{ui:assembly.refresh.confirmTitle}}** が出ます。元部品の名前、選択ファイルの名前、同じ元部品を共有する配置数、保存済み参照への影響を確認してください。非表示・抑制中の配置と入れ子の組も更新対象です。入れ子に欠損や循環があるなど全配置数を数えられない場合は、その旨を表示します。

選択ファイルが元部品を編集して保存したものだと確認できたときだけ **{{ui:assembly.refresh.confirmSameSource}}** を押します。別の部品なら **{{ui:assembly.refresh.confirmCancel}}** またはEscで戻り、置換操作を使ってください。最初の焦点は戻るボタンにあります。確認中に文書や元部品が変わった場合も、更新を確定しません。同じ内容のファイルでは確認を出さず、履歴も増やしません。
