## 著作権上の扱い

- **規格本文は複製していない。** 条文・図・注記は一切写していない。
- **数値はメーカーの技術資料・官公庁の CAD 製図基準・工学系の公開資料から写した**事実であり、**原典(JIS 規格票)と食い違う可能性がある。**
- 食い違いの恐れがある行には各 JSON の `verified: false` と `note` を付け、この README の一覧で **要確認** とした。
- 規格番号・名称は全件、版(年)は 14 件を **日本規格協会(JSA)の書誌ページ**などで照合した(残り 9 件は要確認)。**規格票そのものは見ていない。**
- 規格本文をそのまま転載しているとみられるサイト(`kikakurui.com`、`jis.eomec.com` など)は**数値の出典に使っていない。** 番号と名称の存在の確認にだけ使った箇所は、その旨を `note` に書いた。
- 「用途による線の名称」の**用途の説明はこの調査による短い要約**であり、規格の文言ではない。

## 確認の基準(P7 と同じ)

| 印 | 意味 |
|---|---|
| **確認済み** | 独立した 2 件以上の公開資料が同じ値を示し、食い違いが無かった |
| **要確認** | 資料が 1 件しか得られなかった、または資料どうしで値が食い違った |
| **得られず** | 数値が見つからなかった。JSON では `null`、`verified: false` |

**推測で数値を書いた行は 1 つも無い。** 得られなかったものは `null` のままにした。

> **独立性について。** `toishi.info` と `d-engineer.com` のはめあい表は、値も誤植も同じで、**同じ出どころとみられるので 1 件として数えた。**

## JSON の形

```json
{
  "standard": "JIS Z 8312",
  "edition": "1999",
  "title": "製図—表示の一般原則—線の基本原則",
  "scope": "どの表か",
  "sourceUrls": ["…"],
  "verified": false,
  "unit": "mm",
  "columns": { "width": "線の太さ(mm)" },
  "notes": ["…"],
  "rows": [ { "width": 0.5, "verified": true, "note": "" } ]
}
```

- 数値の列は **number**(得られなかったところは `null`)。欄名は英字の短い名で、意味は各 JSON の `columns` にある。
- ファイル全体の `verified` は「全行が確認済みか」。1 行でも要確認があれば `false`。
- 行の `verified` は「その行のすべての数値が 2 件以上の独立した資料で一致したか」。
- **表が複数ある規格**(B 0405 の長さ/面取り/角度、B 0419 の 4 表、Z 8311 の様式)は、**トップの `rows` を空にして、名前付きの入れ子(`lengthExcludingChamfer.rows` など)に分けた。**

# 統括が判断する必要がある点

## 1. 版の違い(番号は正しい、版が古い/新しい)

1. **JIS B 0405 と JIS B 0419 は 1991 年版のまま**で、これが現行。数値は 2 件が一致していて確度が高い。**そのまま使ってよい。**
2. **JIS B 0601 は記号の意味が版で入れ替わっている。** 1994 年版は `Ry` = 最大高さ、`Rz` = 十点平均粗さ。**2001 年版以降(現行 2013)は `Rz` = 最大高さ**で、十点平均粗さは廃止。
   **`surface-roughness-jis-b-0601.json` の数列は 1994 年版の資料から取った。** 実装で「Ra 3.2 / Rz 12.5」と出すとき、**Rz がどちらの意味かを決める必要がある。**
3. **JIS B 0031 も 1994 年版と 2003 年版で図示記号の書き方が変わっている**(三角の記号に数値を添える位置など)。**記号の字形の数値は 1 つも得られなかった。** P8 タスク 34(表面性状)は、**統括が別途図を用意するか、範囲を落とすかの判断が要る。**
4. **JIS B 0001 の線の一覧は 2010 年版の抜粋**しか得られなかった。現行は 2019 年版。**差は照合していない。**
5. **JIS B 0021(幾何公差)と JIS Z 3021(溶接記号)の版が照合できていない。** どちらも P9 の範囲なので、P8 では番号だけ控えて先送りしてよい。

## 2. 資料どうしが食い違う箇所

1. **輪郭のとじしろ側の幅 `d`。**
   - PERSC は「外周余白 c の**外側に**とじ代 20 を足す」(A2 なら左の余白は合計 30)。
   - 機械製図(s-projects)は「用紙の端から 20 以上」(A2 でも合計 20)。
   - **`paper-sizes-jis-z-8311.json` は 20 を入れたが全行 要確認。** 図枠の左端の位置が 10mm ずれるので、**P8 タスク 6(用紙と枠)の前に決める必要がある。**
2. **推奨尺度の両端。**
   - 検索結果が示した JIS の表は 倍尺 50:1〜2:1 / 縮尺 1:2〜1:10000。
   - ものづくりのススメ は 倍尺 500:1〜2:1 / 縮尺 1:2〜1:500。
   - **両方に共通する 14 個だけを確認済みにした。** JIS は「推奨尺度に 10 の整数乗を掛けて広げてよい」としているので、どちらも間違いではない可能性がある。**P8 の尺度の選択肢を 14 個にするか、広げるかを決める。**
3. **表面性状のカットオフ値 λc の区切り方**がリネックスとパンチ工業で 1 段ずれる。**全行 要確認。** P8 では λc を使わないなら、この列は落としてよい。
4. **といし.info / d-engineer のはめあい表には誤植がある。**(JS6 の 180〜200 を ±4.5、h7 の 400〜450 を「+/−63」、H9 の 315〜355 で + が落ちている)。この表では OSG と IT 公差の値で直したが、**同じ出どころの資料を引くときは注意が要る。**

## 3. 得られなかったもの(P8 の着手前に決める)

1. **矢印の大きさ(長さ・開き角)と、寸法まわりのすきま。**
   JIS Z 8317-1 の**附属書 A** に入っており、公開資料に数値が無かった。**`dimensioning-jis-z-8317.json` は全部 `null`。**
   計画書 §0.9 の候補(長さ = 文字高さ 3.5mm、開き角 15°、すきま 1mm / 2mm / 8mm)は**裏づけが取れなかった。**
   **→ 統括の判断: (a) 候補値を `要確認` つきで採る(P3 のねじ・P7 の規格部品と同じ流儀)か、(b) 利用者に原典で照合してもらうか。作業担当の推奨は (a)。**
2. **破線・一点鎖線・二点鎖線の要素の長さ**(線分・すきま・点)。JIS Z 8312 の表にあるはずだが数値が得られなかった。**計画書 §0.9 の候補(破線 3-1、一点鎖線 10-1-1-1)も裏づけなし。** 同じく (a) を推奨。
3. **文字高さごとの線の太さ dA / dB の丸めた値。** 比の規則(h/14、h/10)は 2 件で確認できたが、各段の丸めた値は**規格本文の転載サイトにしかなかったので採らなかった。** JSON には h/14・h/10 を JIS Z 8312 の数列に丸めた候補を入れ、**全行 要確認**にした。
4. **表題欄の大きさ。** JIS Z 8311 は位置(右下)しか定めていないとみられる。様式は ISO 7200 系。**P8 の表題欄の寸法は PointerCAD の設計判断になる。**
5. **IT 公差の IT01〜IT4 と IT12〜IT18。** 得られなかった。計画書 §0.8 は「IT5〜IT12 を重点」としているが、**IT12 が無い。** → **範囲を IT5〜IT11 に縮めるか、統括が別途用意するか。**
6. **断面・部分拡大・第三角法の記号の寸法**(JIS Z 8316 / Z 8315-2)。数値は得られなかった。第三角法の記号の**形**は広く知られているので、実装は形から起こすことになる。

## 4. ISO との差

- **JIS B 0401-1/-2 は ISO 286-1/-2 と同じ**(2016 年版で ISO コード方式へ全面移行)。数値の差は無いとみてよい。
- **JIS Z 8317-1 は ISO 129-1:2004 の翻訳**、**JIS Z 8316 は ISO 128 系**、**JIS Z 8315 は ISO 5456 系**、**JIS B 0601 は ISO 4287 系**。いずれも技術的内容を変えない翻訳とされている。**ISO の英文資料を出典に足せば、確認済みの行を増やせる余地がある。**
- **JIS P 0138 の B 列だけは ISO と非互換**(JIS B0 の面積は 1.5m²、ISO B とは別物)。**P8 は A 列だけなので影響しない。**
- **JIS B 0405 / B 0419 は ISO 2768-1/-2 と同じ**とされる。
