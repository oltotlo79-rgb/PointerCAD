# 文字をスケッチの輪郭にする

文字の輪郭を線分と曲線にして、作図面へ配置できます。銘板や刻印の形を作るときに使います。

1. 文字を置く作図面を選びます。
2. 「作図」の一覧から「文字をかく」を選びます。
3. 作図面をクリックし、文字の原点を決めます。
4. 「文字列」「文字の高さ」「文字の角度」「文字の揃え方」を入力して「決定」を押します。

文字列は1〜1000文字です。高さには数値のほか、パラメータの名前を使った式も入力できます。高さの単位は表示設定のmmまたはinch、角度の単位は度です。たとえば高さに「文字高さ * 2」を指定すると、後から「文字高さ」を変更したときにも輪郭の大きさが追従します。

揃え方は左・中央・右から選びます。文字の角度は、選んだ作図面の中での回転を表します。

確定すると、輪郭は通常の線分と制御点スプラインとして一覧へ追加されます。「8」などの内側の輪郭も残ります。必要な輪郭で面を張ると、押し出しの材料にできます。文字の追加全体を取り消す場合は「元に戻す」を1回押します。

確定後は、文字列そのものを編集する欄は残りません。文章を変えたい場合は作成を取り消してから入力し直してください。輪郭の線や制御点は、ほかのスケッチ要素と同じ方法で編集できます。

空白だけの文字列、高さ0以下、利用する字体に含まれない文字は作成できません。画面下に理由が表示されます。3Dスケッチでは文字を置く平面を決められないため、作図面を持つスケッチへ切り替えて使ってください。
