# 途中まで戻して確かめる(タイムライン)

作ったものは、左の「モデルブラウザ」に**作った順**で上から並びます。その行の左端に細いつまみが付いていて、つまみを上へ動かすと、**そこまで作ったところの形**が 3D の絵に出ます。あとから作ったものは、いったん見えなくなります。

「この穴をあける前は、どんな形だったかな」と確かめたいときに使います。

## つまみを動かす

1. 左の「モデルブラウザ」で、「基準」か「ソリッド」の行の**左端**を見ます。行ごとに小さなまるが縦に並んでいます。
2. 戻したいところのまるをクリックします。3D の絵が、その行までを作ったところの形に変わります。
3. それより下の行は字がうすくなります。うすい行は「いまは作られていない」という意味です。
4. 元に戻すときは、**もう一度同じまるをクリック**します。いちばん下の行のまるをクリックしても元に戻ります。

同じまるを続けて 2 回クリックしても元に戻ります。

## 戻しているあいだの目印

途中まで戻しているあいだは、画面のいちばん下の帯に

> 途中まで戻しています(3 件目 / 5 件)

と出たままになります。**この字が出ているあいだは、作ったものの一部がわざと隠れています。**「作ったはずのものが消えた」と思ったら、まずこの字が出ていないかを確かめてください。

## 戻していても、なくなりません

- つまみを動かしても、**作ったものは 1 つも消えません。**見えなくなっているだけです。
- つまみの場所は、保存するファイルには入りません。**保存して開き直すと、いつも全部作られたところから始まります。**
- 途中まで戻したまま保存しても、ファイルには全部が入ります。あとの行が抜けたファイルにはなりません。
- 「元に戻す」(Ctrl+Z)の対象にもなりません。つまみを動かしたことは、形を変えた操作ではないからです。

## 戻したまま新しく作ると

途中まで戻したまま新しいものを作ると、それは**いちばん最後**に足されます。そのままだと、作ったばかりのものが隠れて見えないので、**つまみは自動でいちばん下へ戻ります。**帯に

> 新しく作ったものを出すため、最後まで戻しました。

と出ます。作ったものはそのまま画面に出ているので、続けて作業できます。

## 抑制と何が違う?

似ていますが、目的が違います。

| | つまみ(タイムライン) | 抑制 |
|---|---|---|
| どこで | 行の左端のまる | 行の「⋮」から「抑制する」 |
| 何が隠れる | そこから下**すべて** | 選んだ **1 つだけ** |
| 保存すると | 残らない(開き直すと全部出る) | 残る(開き直しても抑制されたまま) |
| 使うとき | 途中の形を見比べる | ある加工だけ試しに外す |

抑制した行は、つまみで戻していない場所でも「抑制中」の札が付いたままです。つまみで戻したときも、抑制した行はそのまま並んで見えます。

## うまくいかないとき

| 困りごと | 見るところ |
|---|---|
| 作ったものが 3D の絵に出ない | 画面下の帯に「途中まで戻しています」と出ていないか確かめます。出ていたら、いちばん下の行のまるをクリックします |
| つまみのまるが出ない | 「基準」「ソリッド」の節が畳まれていないか確かめます。節の名前をクリックすると開きます。スケッチの行にはつまみは付きません |
| 戻しても形が変わらない | その行より下に、形を変えるものが無いときは見た目が変わりません。1 つ上の行のまるも試してください |
