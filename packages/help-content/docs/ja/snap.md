# 点にぴったり合わせる(吸着)

線や点をかくとき、近くにある大事な場所へ自動でぴったり合わせられます。画面の上の「吸着」で入と切を切り替えます。はじめは入になっています。

## 合わせられる場所

「吸着」の右にある一覧に、合わせる場所の種類が並んでいます。カーソルを重ねると名前と説明が出ます。上の 5 つが「点に合わせる」もので、下の 4 つ(角度・延長線・垂線・平行線)は「向きをそろえる」ものです。向きをそろえるほうは「向きをそろえる(直交・角度・延長線)」を見てください。

| 種類 | ボタンの図柄 | どこに合うか |
|---|---|---|
| 端点 | 線の先に四角 | 点、線や円弧の端 |
| 交点 | ばつ印の交わりに四角 | 2 本の線が交わるところ |
| 中点 | 両端に印のある線の、まんなかに四角 | 線のまんなか、円弧のまんなか |
| 中心 | 円のまんなかに四角 | 円や円弧の中心 |
| 方眼 | 十字と点の並びのまんなかに四角 | 方眼の交わるところ |

どの図柄にも同じ四角が入っています。これは、合ったときに画面に出る青い四角の印と同じ形です。

近くに何種類も候補があるときは、上の表の上にあるものが選ばれます。たとえば線の端と方眼が同じくらい近いときは、線の端に合います。

種類ごとに入と切を選べます。いま入になっているものは青い下地で分かります。たとえば「方眼」だけを切にすれば、方眼は無視して線の端だけに合います。「吸着」そのものを切にすると、どれにも合わなくなり、一覧のボタンも効きません。

## 見え方

合っているときは、その場所に四角い青い印が出ます。そのままクリックすると、その場所の座標が入力欄に入るので、あとは Enter を押すだけです。

合わせようとしている線や点は、色が変わって分かるようになっています。

## 合わせる場所は「作図面」の上で決まります

方眼に合わせるときの方眼は、いま選んでいる作図面(XY・XZ・YZ)のものです。作図面を変えると合う場所も変わります。作図面については「作図面を選ぶ」を見てください。

## うまく合わないとき

- 印が出ないときは、少し近づけてください。合う範囲はカーソルからおよそ指 1 本ぶんです。
- 意図しない場所に合うときは、その種類を切にしてください。
- 数値をそのまま打ちたいときは、クリックせずに入力欄へ書けば、吸着は使われません。
