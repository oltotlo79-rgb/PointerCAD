# 基準の軸・点・座標系を作る

形そのものにはならないけれど、位置や向きを決めるときの手がかりになるものを作れます。回転の軸に使ったり、離れたところの位置を測る起点にしたりできます。

作り方は「作図面」の一覧の下のほう、**基準**のところに並んでいます。

| 作るもの | 何に使うか |
|---|---|
| 基準軸 | 回す向き・並べる向き・作業平面を傾ける軸 |
| 基準点 | 位置の起点、作業平面や軸を決める点 |
| 座標系 | 原点と 3 つの向きをまとめて決めておく |

どれも画面の中に小さな入力欄が浮かびます。数値は式でも入れられます。Tab で次の欄、Enter で決定、Esc で取消です。

## 基準軸を作る

1. 「作図面」の一覧から「基準軸」を選びます。
2. 「決め方」を選びます。

| 決め方 | 何をするか |
|---|---|
| 2 点 | 通したい 2 点を続けて入れます。1 点目から 2 点目へ向かう向きになります |
| 辺 | 立体のまっすぐな辺を選んでおくと、その辺と同じ向きの軸になります |
| 面の法線 | 立体の平らな面を選んでおくと、その面に垂直な軸になります |
| 2 面の交線 | 平らな面を 2 つ選んでおくと、2 面が交わる線が軸になります |

「2 点」を選んだときは、決定を押すと 1 点目・2 点目を続けて聞かれます。2 点目は「相対」が選ばれていて、1 点目からのずれで入れられます。

辺や面から作るときは、**先に立体の辺や面をクリックして選んでおきます。** 選んでいないと「まっすぐな辺を 1 本選んでから決定してください。」のように出て、何も作られません。2 つの面が平行のときは交わる線がないので「2 つの面が平行なので交線がありません。」と出ます。

できた軸は、細い線でビューポートに出ます。作業平面を傾けるときの「軸」や、座標系の向きにそのまま選べます。

## 基準点を作る

1. 「作図面」の一覧から「基準点」を選びます。
2. 「決め方」を選びます。

| 決め方 | 何をするか |
|---|---|
| 座標 | 位置を数値(または式)で入れます |
| 頂点 | 立体の頂点を選んでおくと、その位置になります |
| 辺の中点 | 立体の辺を選んでおくと、その真ん中になります |
| 面の中心 | 立体の面を選んでおくと、その中心になります |

「座標」を選んだときは、決定を押すと位置を聞かれます。ビューポートをクリックしても、その位置が欄に入ります。

できた点は、小さな印でビューポートに出ます。作業平面の 3 点や基準軸の 2 点として選べます。

## 座標系を作る

1. 「作図面」の一覧から「座標系」を選びます。
2. 原点の位置を入れて Enter。
3. 「X 軸」と「Y 軸」の向きを選んで Enter。

X・Y には、ワールドの X・Y・Z と、これまでに作った基準軸が並びます。**3 つ目の向き(Z)は自動で決まります。** X と Y が直角になっていなくてもかまいません。決めるときに直角になるよう整えられます。

X と Y に同じ向き(または平行な向き)を選ぶと座標系が決まらないので、「2 つの軸が平行なので座標系が決まりません。」と出ます。向きの違う軸を選んでください。

できた座標系は、原点から出る 3 色の短い矢印で出ます。赤が X、緑が Y、青が Z です。

## 表示と取り消し

- 基準の軸・点・座標系は、形そのものではないので厚みをつける対象にはなりません。位置や向きを決めるための目印です。
- 元に戻す(Ctrl+Z)を 1 回押せば、作ったものは消えます。作るときに入れた点もいっしょに消えます。
- 作ったものを使っている作業平面がある状態で元に戻すと、その作業平面は「見つかりません」と出ます。作り直すか、作業平面のほうも元に戻してください。

## うまくいかないときは

決められなかった理由は、画面の下の帯に日本語で出ます。

- 「頂点を 1 つ選んでから決定してください。」— 先に立体の頂点をクリックしてください。
- 「平らな面を 2 つ選んでから決定してください。」— Shift を押しながらクリックすると 2 つ目を足せます。
- 「2 点が同じ位置のため、軸の向きが決まりません。」— 2 点目を 1 点目と違う位置にしてください。
- 「…の指定が循環しています。」— たどっていくと自分自身に戻る指定になっています。基準にするものを別のものへ変えてください。
