# 作図したデータの保存場所と通信

PointerCADは、開いた文書の形や数式を端末内で計算します。作図した内容を計算用のサーバーへ送りません。Web版を開くときは、画面・計算部・説明書のファイルを取得するために通信します。

## 何をどこへ保存するか

| 保存するもの | 保存場所 | 別の端末で使うには |
|---|---|---|
| 自分で保存した部品・組立・図面 | 保存画面で選んだ場所。場所を選べないブラウザーでは、ブラウザーのダウンロード先 | 保存したファイルを移し、移した先で「開く」から選びます |
| 作業中に自動で残す控え | このブラウザー、またはデスクトップ版が端末内で管理する保存領域 | 元の環境で復元し、文書のファイルとして保存してから移します |
| 表示設定と最近使ったファイルの名前 | このブラウザー、またはデスクトップ版の保存領域 | 文書を移しても表示設定は自動では移りません。移した先で設定します |
| 通信なし利用のためのアプリ・計算部・説明書 | 準備を行ったブラウザーの保存領域 | 移した先のブラウザーで、通信できる間に準備し直します |

部品は `.pcad`、組立は `.pcada`、図面は `.pcadd` という名前のファイルです。「名前を付けて保存」を使うと、元の文書とは別の名前や場所へ保存できます。キーはCtrl+Shift+Sです。

保存場所を選べない環境では、「保存」を押すたびにダウンロードが行われます。ブラウザーのダウンロード一覧で最新のファイルを確認してください。古いファイルを整理する前に、残すファイルを開き、必要な内容が入っていることを確認します。

## 自動の控えだけに頼らず、文書を保存する

自動保存は、初期設定では変更のある文書の控えを5分ごとに残します。最後に控えを残した後の変更は、まだ残っていない場合があります。作業の区切りには「保存」を押してください。

次の起動で「前回の作業が残っています」と表示されたら、「復元する」で続きを開けます。復元しただけでは文書のファイルを保存したことにはなりません。内容を確認して保存してください。自分で保存した後は、その文書の自動の控えは消えます。

ブラウザーのサイトデータを消すと、自動の控え・設定・通信なし利用の準備も失われる場合があります。別のブラウザーや別の利用者で開いても、元の保存領域は引き継がれません。消す前に必要な文書をファイルとして保存し、保存先を確認してください。

## 外部のアプリや案内を開くとき

加工ソフトへ渡す操作では、先にSTEP・STL・3MFなどのファイルを書き出します。PointerCADが加工先のWebサイトへ形を自動送信することはありません。案内のページを開く操作は、そのページを表示するための通信を行います。

書き出したファイルを外部のアプリで開いた後や、自分で別のサービスへファイルを渡した後の扱いは、そのアプリやサービスの設定によります。PointerCAD内の保存と、外部へ渡す操作は別です。
