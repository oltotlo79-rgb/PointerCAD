# 立体から線を取り込む(投影・断面)

すでに作った立体のかたちを、いまの作図面へ線として取り込めます。取り込んだ線は、ふつうにかいた線と同じように面を張る境界にも、押し出しの材料にも使えます。

道具は「作図」の隣、**編集**の一覧のいちばん下に「投影」「断面」として並んでいます。

| 道具 | すること | 押すもの |
|---|---|---|
| 投影 | 立体の面の外周や辺を、作図面へまっすぐ写す | 立体の面、または辺 |
| 断面 | 立体と作図面が交わってできる線を取り込む | 立体そのもの |

## 投影で面や辺を写す

1. 取り込みたい作図面を選びます(ツールバーの「作図面」)。
2. **編集**の一覧から「投影」を選びます。選ぶものの種類が自動で「面」に変わります。
3. 写したい面の上にマウスを乗せると光ります。**クリックすると、その面の外周が作図面の上に線として現れます。** Enter は要りません。
4. 続けて別の面をクリックすれば、何枚でも取り込めます。終わるときは Esc を押すか、別の道具を選びます。

辺を 1 本だけ写したいときは、画面の下の帯の「選ぶもの」を**辺**に切り替えてから(`2` キーでも切り替わります)、その辺をクリックします。丸い穴の辺を写すと、作図面には同じ大きさの円が現れます。

先に面や辺を選んでおいてから「投影」を押しても同じ結果になります。選んでいたものをまとめて取り込むので、取り消し(Ctrl+Z)は 1 回で全部戻ります。

## 断面で切り口の線を取り込む

1. 切り口を取りたい位置に作図面を用意します。基準の 3 面(XY・XZ・YZ)のほか、「好きな向きの作業平面を作る」で作った平面も使えます。
2. **編集**の一覧から「断面」を選びます。選ぶものの種類が「立体」に変わります。
3. 立体をクリックすると、**その立体と作図面が交わってできる線**が作図面の上に現れます。

立体と作図面が交わっていないときは線ができません。そのときは画面の下の帯に「立体と作図面が交わりません。作図面の位置を見直してください。」と出ます(立体はそのまま残ります)。

## 取り込んだあと

- 取り込んだ線はモデルブラウザに「投影1」「断面1」…として並びます。
- **もとの立体を直すと、取り込んだ線も一緒に変わります。** 板の幅を 40 から 60 に変えれば、投影した輪郭も 60 になります。
- 計算に少し時間がかかることがあり、そのあいだは画面の下の帯に計算中と出ます。
- 要らなくなったらモデルブラウザから消せます。取り消し(Ctrl+Z)は 1 回ぶんです。

## 順序の決まり

**取り込めるのは、このスケッチを使う立体より前に作られた立体だけです。**

たとえば「スケッチ1 を押し出して立体1 を作る」→「スケッチ2 で立体1 を投影する」→「スケッチ2 を押し出して立体2 を作る」という順は問題ありません。

いっぽう、スケッチ2 から作った立体2 を、そのスケッチ2 自身へ取り込むことはできません。自分で自分を参照することになるためです。この順で押すと、帯に「取り込めるのは、このスケッチを使う立体より前に作られた立体だけです。」と出て、何も足されません。別の立体を選ぶか、モデルブラウザで順序を見直してください。

もとの立体を消したときも同じで、帯に「もとになる立体が見つかりません。」と出ます。取り込んだ線は消えたままですが、他のかたちは影響を受けません。

## 覚えておくとよいこと

- **作図面のあるスケッチでだけ使えます。** 3D スケッチ(作図面なし)では、写す先・切る面が決まらないので使えません。
- **作図面に対して傾いた円は、まっすぐな線をつないだ多角形の近似になります。** 作図面と平行な円(たとえば XY 面へ写す、上を向いた穴の辺)はきれいな円のまま写りますが、斜めを向いた円や自由な曲線は、細かい折れ線に置きかえて取り込みます。寸法どおりの円が必要なときは、写した線を下敷きにして円の道具でかき直してください。
- 面を写すと、その面の**外周**だけが線になります。面の中にある穴の輪郭は写りません。穴の輪郭が要るときは、その穴の辺を「辺」の種類で選んで写してください。
