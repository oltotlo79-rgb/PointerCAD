# 部品を差し替える・組を置く

部品を差し替えるときは、左の一覧で部品を1つ選び、上の **組む** から **部品を差し替える** を選びます。新しい `.pcad` ファイルを選ぶと、既存の合致とジョイントをできるだけ同じ対象へ選び直します。

選び直せない対象がある場合だけ、件数とともに確認が出ます。**差し替える**で確定し、**取り消す**またはEscで元のまま閉じます。すべて選び直せた場合は確認を増やさず、そのまま確定します。

別のアセンブリをまとめて置くときは **組を置く** を選び、`.pcada` ファイルを開きます。置いた組は左の一覧で畳んだり開いたりできます。自分自身を含む組や深すぎる入れ子は、理由を表示して置きません。

どちらの確定も「元に戻す」1回で操作前へ戻せます。
