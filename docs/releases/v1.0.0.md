## PointerCADについて

PointerCADは、「前の点から右へ40mm」「板厚の2倍の位置」のように、作りたい形の決め方をそのまま入力できる3D CADです。座標・相対距離・角度・数式を使って描き、マウスで形を確かめながら立体や加工を加えられます。Windows・Linuxのデスクトップ版と、ブラウザで使えるWeb版を用意しています。

無料で使えるオープンソースソフトウェア(ライセンス: Apache-2.0)として公開します。

## 主な機能

### 座標とマウスで描く

点・線分・円・円弧・矩形・多角形・楕円・スプラインを、コマンド欄からの数値入力とマウス操作を組み合わせて描けます。線分どうしが交わったところには自動で共有する点を作り、その点を動かして途中を曲げたり、はみ出した区間だけを削除したりできます。寸法や位置の拘束、3Dスケッチにも対応しています。

### 名前付きの数式で寸法を管理する

`板厚`や`穴径`のような日本語の名前を付けた数値で寸法を管理できます。例えば押し出しの距離を`板厚 * 2`のように指定すると、`板厚`の値を変えるだけで関係する寸法がまとめて追従します。式は保存して開き直した後も編集できます。

### 立体を作る・加工する

押し出し・回転・スイープ・ロフトで立体を作り、箱・球・円柱などの基本形状、立体の結合・切り抜きも使えます。穴・ねじ穴・面取り・角丸め、ミラー・配列、平面による切断、コイルばねなどの加工を、操作を履歴に残しながら積み重ねられます。元のスケッチや加工の値をあとから編集すると、続く形も再計算されます。

### 組み立てる

複数の部品を面や軸の関係で配置・合致させ、回転・スライドの動きや部品どうしの干渉を確認できます。ボルト・ナット・座金・軸受などの規格部品、分解表示、部品表にも対応しています。

### 図面を作る

部品から三面図・断面図・詳細図を作り、寸法・公差・幾何公差・表面性状・溶接記号を記入できます。元の部品を編集すると図面も更新され、部品表・穴表を添えてPDF・SVG・DXFで出力できます。

### 板金を設計する

基板からフランジや指定線の曲げを作り、切欠きを加えて展開できます。板厚・曲げ半径・K係数にも名前付きの数式を使えるので、寸法違いの構成を切り替えて折り曲げた形と展開の両方を確かめられます。展開DXF、折曲げ・展開STEP、曲げ指示を含む図面を出力できます。

### 形を調べる・強度を検討する

距離・角度・体積・質量の測定、断面表示、肉厚・オーバーハングなど3Dプリント向けの点検を備えています。梁の曲げ・軸のねじり・ボルトの引張は、寸法や荷重を入力して簡易計算でき、使用する公式・数値・材料値の出典と適用条件を確認しながら形の検討に使えます。

### 作図を自動化する

JavaScriptで点・線・面・立体や穴をまとめて作る処理を書き、よく使う処理を名前付きの道具として登録できます。自動で作った形も通常の履歴に残るため、あとから画面上で寸法を編集できます。処理全体をUndo1回で戻せるので、手作業と自動化を行き来しながら試作できます。

### 保存・データの受け渡し

編集可能な文書として保存・再読込でき、自動保存からの復元にも対応します。STEP・STL・DXFの読み書きに対応し、他のCADで作った形の取り込みや、3Dプリント・加工へ渡すデータの書き出しに使えます。

## 数式・関数を使った設計(完成後に確定する)

数式や関数で曲線・曲面を定義し、設計に使う立体や点につなげる機能は、このリリースノート作成時点でも実装・検証が続いています。対応する式の種類、精度、操作方法が確定した時点で、本章の内容を書き直します。

## ヘルプと取扱説明書

アプリ内でF1キーからヘルプを開き、検索や章ごとの案内から操作を探せます。「初めての作図」など目的別のヘルプも用意しています。配布物には取扱説明書(HTML・PDF、全7分冊)を同梱します。

## 対応環境

- デスクトップ版: Windows 10/11(x64)、Linux(x64、AppImageで配布)
- Web版: 最新のChrome・Edge・Firefoxで、ダウンロード不要でブラウザから使えます

デスクトップ版とWeb版は同じ機能を持ちます(保存方法などプラットフォーム固有の部分を除く)。
