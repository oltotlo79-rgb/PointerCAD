# 球の表面に点を置く

球を選ぶと、球の表面に緯度・経度の**案内の線**が出ます。線が交わっているところをクリックすると、そこに点ができます。地球儀の緯線・経線と同じ考え方です。

この点は「どの球の、どの緯度・経度か」で覚えています。**あとから球の大きさや位置を変えると、点も球の表面に貼り付いたまま一緒に動きます。**

## 案内の線を出す

1. 「選択」で球をクリックします(左の一覧の行を押しても選べます)。
2. 球の表面に、細い灰色の線が縦横に出ます。
3. 選ぶのをやめると線は消えます。

球がまだ無いときは、「ソリッド」の「作る」から「球」を置いてください(→ 球・箱・円柱・円錐・トーラスを置く)。

## 交点をクリックして点を置く

1. 球を選びます。
2. 「ソリッド」の「作る」を押して、一覧から「球面上の点」を選びます。
3. 小さな入力欄が出ます。そのまま球の上へマウスを動かすと、いちばん近い交点に吸い付き、欄の「緯度」「経度」がその値に変わります。
4. そこでクリックすると点ができます。続けて別の交点をクリックすれば、何点でも置けます。

やめたいときは Esc を押します。

交点から離れたところをクリックしたときは、点はできず、押した球を選び直したことになります。

## 緯度と経度を数字で入れる

交点をクリックする代わりに、入力欄に数を打っても点を置けます。

1. 球を選んで「球面上の点」を押します。
2. 「緯度」と「経度」に数を入れます。
3. Enter を押すか「決定」を押します。

- **緯度**は赤道が 0 度、北(上)が +90 度、南(下)が −90 度です。−90 度から 90 度までしか入れられません。
- **経度**は横向きの角度です。0 度が X の向き、そこから Y の向きへ回るほど大きくなります。360 度回ると元に戻るので、`450` と書けば `90` と同じ場所になります。

`30*2` のような式も書けます。あとから直すときも式のまま残ります。数を入れずにそのまま Enter を押すと、緯度 0 度・経度 0 度(赤道の X の向き)に点ができます。

## 線の間隔を変える・いつも出す

球を選ぶと、右のプロパティに「球面の案内線」が出ます。

- **線の間隔**: はじめは 5 度ごとです。`10` と入れれば 10 度ごとの粗い線に、`2` と入れれば細かい線になります。式も書けます。**1 度から 90 度まで**で、その外の数を入れると線は出ません。
- **いつも出す**: 入にすると、球を選んでいなくても案内の線が出たままになります。球が 2 つ以上あるときは、最後に作った球に出ます。

線を細かくすると交点も増えますが、クリックしたときに吸い付く場所は、いつでもいちばん近い交点です。

## 置いた点をあとから直す

置いた点を選ぶと、右のプロパティに「球の上の位置」が出ます。ここで緯度と経度を直せます。数を変えると、点は球の表面をすべるように動きます。

上の「基準」には、どの球の上の点なのかが出ます。もとの球を消してしまうと「球が見つかりません。球を選び直してください。」と出るので、点を置き直してください。

## 球を変えると点も動く

球の半径を 10 mm から 20 mm に変えると、球面上の点も外へ動いて、球の表面に残ります。球の中心を動かしたときも同じです。

その点から線を引いたり、面を張ったりしていれば、それらも一緒に動きます。球のまわりに骨組みを作ってから、あとで球の大きさだけを決め直す、という作り方ができます。
