# 面を張る・色を変える

囲まれたところを塗りつぶして「面」にできます。面は、あとで厚みを付けて立体にするための土台になります。

## 点を選んで張る

1. 上の「スケッチ」で「面」を選びます。
2. 囲みたい形の角になる点を、**まわる順に**クリックします。
3. Enter を押します。

となりあう点のあいだには線が自動で引かれ、最後の点と最初の点もつながります。点は 3 つ以上必要です。

「面」を選んだあとは、そのまま Enter を押せるようになっています。どこか別のところをクリックしたあとで Enter が効かなくなったときは、3D の絵の中を一度クリックしてから押してください。

## 線や円弧を選んで張る

同じように「面」を選び、囲んでいる線や円弧を**つながる順に**クリックして Enter を押します。切れ目のない円を 1 つ選んだときは、その円の中が面になります。

点と線をまぜて選ぶことはできません。どちらか一方にそろえてください。

## 色を変える

面をクリックして選ぶと、右の「プロパティ」に「色」の見本が 8 つ出ます。押すとその色になります。いま使っている色には枠が付きます。はじめは青みがかった色になっています。

色は面ごとに決められます。ほかの面の色は変わりません。

## 何を囲んでいるかを見る

面を選ぶと、右の「プロパティ」に「境界」の並びが出ます。選んだ順にそのまま並んでいます。行をクリックすると、その線や点が選ばれて 3D の絵の中で光ります。どこがつながっていないのかを探すときに使えます。

## うまく張れないとき

下の帯に「面を作れませんでした:」に続けて理由が出ます。よくある原因は次のとおりです。

| 出る文 | 直し方 |
|---|---|
| 面を張るものが選ばれていません | 囲んでいる線か、角になる点を先にクリックします |
| 点と線をまぜて面を張ることはできません | 点だけ、または線だけを選び直します |
| 面を張るには点が 3 個以上必要です | 点をもう少し選びます |
| 選んだ線・円弧の端がつながっていません | 端どうしがぴったり重なるように、吸着を使ってかき直します |
| 最後の端が最初の端に戻っていません | 囲みが 1 周していません。足りない線を足します |
| 選んだ点が同じ平面に乗っていません | 高さ(Z)がそろっているか確かめます |

うまくいかなくても、かいた線や点はそのまま残ります。選び直せば何度でもやり直せます。
