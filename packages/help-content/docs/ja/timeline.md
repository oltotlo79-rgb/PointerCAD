# 途中まで戻して確かめる(タイムライン)

作ったものは、左の「モデルブラウザ」に**作った順**で上から並びます。その行の左端に細いつまみが付いていて、つまみを上へ動かすと、**そこまで作ったところの形**が 3D の絵に出ます。あとから作ったものは、いったん見えなくなります。

「この穴をあける前は、どんな形だったかな」と確かめたいときに使います。

## はじめての案内

立体を 2 つ目まで作ると、画面のいちばん下の帯に一度だけ

> 左端のつまみを引くと途中まで戻せます。

と出ます。つまみの操作を知らせるための案内で、押さなくても消え、次からは出ません。

## つまみを動かす

1. 左の「モデルブラウザ」で、「基準」か「ソリッド」の行の**左端**を見ます。行ごとに小さなまるが縦に並んでいます。
2. 戻したいところのまるをクリックします。3D の絵が、その行までを作ったところの形に変わります。
3. それより下の行は字がうすくなります。うすい行は「いまは作られていない」という意味です。うすい行を選んで右の「プロパティ」を見ると、体積などの欄に「まだ作られていません(つまみより後ろ)」と出ます。これは失敗ではありません。
4. 元に戻すときは、**もう一度同じまるをクリック**します。いちばん下の行のまるをクリックしても元に戻ります。

同じまるを続けて 2 回クリックしても元に戻ります。

## 戻しているあいだの目印

途中まで戻しているあいだは、画面のいちばん下の帯に

> 途中まで戻しています(3 件目 / 5 件)

と出たままになります。**この字が出ているあいだは、作ったものの一部がわざと隠れています。**「作ったはずのものが消えた」と思ったら、まずこの字が出ていないかを確かめてください。

## 戻していても、なくなりません

- つまみを動かしても、**作ったものは 1 つも消えません。**見えなくなっているだけです。
- つまみの場所は、保存するファイルには入りません。**保存して開き直すと、いつも全部作られたところから始まります。**
- 途中まで戻したまま保存しても、ファイルには全部が入ります。あとの行が抜けたファイルにはなりません。
- 「元に戻す」(Ctrl+Z)の対象にもなりません。つまみを動かしたことは、形を変えた操作ではないからです。

## 途中に差し込む

途中まで戻したまま新しいものを作ると、それは**つまみのところに差し込まれます。**いちばん最後ではありません。帯に

> つまみのところへ差し込みました。つまみは差し込んだ行へ進みました。

と出て、つまみは差し込んだ行へ 1 つ進みます。作ったものはそのまま画面に出るので、続けて作業できます。

「押し出し → 穴 → 面取り」と作ったあとで、**押し出しのすぐ後ろにもう 1 つ押し出しを足したい**、というときに使います。

1. 「押し出し1」の行のまるをクリックして、そこまで戻します。
2. いつもどおり新しい押し出しを作ります。
3. 一覧では「押し出し1」の次に入り、その後ろに「穴1」「R面取り1」が並びます。
4. 穴と面取りは、**新しくなった形の上で作り直されます。**

差し込みは「元に戻す」(Ctrl+Z)1 回で取り消せます。

## 作る順序を入れ替える

一覧の「基準」「ソリッド」の行は、**上下へドラッグ**すると作る順序を入れ替えられます。

1. 動かしたい行を押したまま、上か下へ動かします。
2. 落ちる場所に**青い線**が出ます。そこで指を離すと、その順序に変わります。
3. その場所へは移せないときは、線が**赤い破線**になります。離しても順序は変わりません。
4. やめたいときは、離す前に **Esc** を押します。

マウスのドラッグが使いにくいときは、行の「⋮」から **「1 つ上へ」「1 つ下へ」**を押しても同じことができます。押せないときは、その項目に指を乗せると理由が出ます。

入れ替えは「元に戻す」(Ctrl+Z)1 回で元の順序に戻ります。

### 入れ替えられないとき

あるものが**別のものの結果を使っている**ときは、使っている側を先に作ることはできません。たとえば「穴1」に付けた「R面取り1」を、穴より前へは動かせません。そのときは画面下の帯に

> 順序を入れ替えられませんでした: R面取り1は穴1を使っているので、穴1より後ろでなければなりません。

と出て、**困っている側の行**(この例では「R面取り1」)に赤い印が付きます。印に指を乗せると同じ理由が読めます。順序は元のままで、形も変わりません。

基準ジオメトリ(作業平面・基準軸・基準点・座標系)と立体は、それぞれの並びの中でだけ入れ替えられます。立体を「基準」の並びの中へ移すことはできません。

## 抑制と何が違う?

似ていますが、目的が違います。

| | つまみ(タイムライン) | 抑制 |
|---|---|---|
| どこで | 行の左端のまる | 行の「⋮」から「抑制する」 |
| 何が隠れる | そこから下**すべて** | 選んだ **1 つだけ** |
| 保存すると | 残らない(開き直すと全部出る) | 残る(開き直しても抑制されたまま) |
| 使うとき | 途中の形を見比べる | ある加工だけ試しに外す |

抑制した行は、つまみで戻していない場所でも「抑制中」の札が付いたままです。つまみで戻したときも、抑制した行はそのまま並んで見えます。

## うまくいかないとき

| 困りごと | 見るところ |
|---|---|
| 作ったものが 3D の絵に出ない | 画面下の帯に「途中まで戻しています」と出ていないか確かめます。出ていたら、いちばん下の行のまるをクリックします |
| つまみのまるが出ない | 「基準」「ソリッド」の節が畳まれていないか確かめます。節の名前をクリックすると開きます。スケッチの行にはつまみは付きません |
| 戻しても形が変わらない | その行より下に、形を変えるものが無いときは見た目が変わりません。1 つ上の行のまるも試してください |
| 新しく作ったものが最後に入ってほしい | いちばん下の行のまるをクリックして戻してから作ります。つまみを動かしていなければ、これまでどおり最後に足されます |
| ドラッグしても順序が変わらない | 落とす場所の線が赤い破線になっていないか確かめます。赤いときは、その場所へは移せません |
| ドラッグしたつもりが選択になった | 少しだけ動かしたときは、押しただけとみなして行を選びます。もう少し大きく動かしてください |
