# 楕円をかく

画面の上の「作図」から「楕円」を選ぶと、つぶれた円(楕円)と、その一部だけ(楕円弧)をかけます。

## かき方

1. 中心にしたい場所をクリックして Enter を押します。
2. 「長半径」と「短半径」を入れて Enter を押します。長半径は長いほうの半分の長さ、短半径は短いほうの半分の長さです。初期は 20mm と 10mm です。
3. 「傾き」を入れて Enter を押すと、楕円ができます。

傾きは、長いほうの向きが作図面の横軸から何度まわっているかです。0 のままなら横長の楕円になります。マイナスの角度も入れられます。

長半径より短半径のほうが大きいと楕円になりません。このときは画面の下の帯に「長軸の半径は短軸の半径より大きくしてください。」と出ます。数を入れ替えてください。

## 一部だけ(楕円弧)にする

傾きを入れる画面に「一部だけ(楕円弧)」というつまみがあります。これを入にして Enter を押すと、続けて「開始角」と「終了角」を聞かれます。

角度は、長いほうの向きを 0 度として、そこから測った角度です。初期は 0 と 360 で、そのまま Enter を押すと切れ目のない楕円になります。たとえば 0 と 180 を入れると、上半分だけの楕円弧ができます。

## 面を張る・厚みをつける

閉じた楕円は、そのまま面の囲みに使えます。「面」の道具で楕円をクリックして Enter を押すと中が塗られ、押し出せば柱や穴の形になります。楕円弧(一部だけ)は閉じていないので、そのままでは面になりません。ほかの線と組み合わせて囲みを閉じてください。

## 実体にしない楕円

傾きを入れる画面には「構築線にする」というつまみもあります。入にすると、位置合わせの目安に使う補助の楕円になり、面の材料にはなりません。

## 直したいとき

かいた楕円は、左の一覧から選んで右のプロパティで中心・半径・傾き・角度を直せます。
