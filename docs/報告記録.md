## 記入様式

```markdown
## YYYY-MM-DD HH:mm 表題

- **依頼**: 利用者の指示の要約
- **実施**: 何をしたか(委譲した場合は担当・モデル・理由も1行で)
- **判断と根拠**: 下した判断と、その根拠(実測値・差分・出力)
- **残件**: 未完了・未確認の事項(無ければ「なし」)
```
