# 追加計画 — 大学数学の入力と計算

作成: 2026-09-11。利用者の「大学卒業相当までで学習する数学記号全て」による追加範囲。原タスクADD-2・ADD-17〜28の13件。本計画時点は全件未完了。実装と受入を完了するまで完成度へ加算しない。

## 0. 対象と完了判定

- 理工系学部の共通数学を基準に、初等演算、微積分、線形代数、複素数、確率統計、集合・論理、数論・組合せ、特殊関数、ベクトル解析、微分方程式・変換を扱う。専門分野による追加希望は利用者へ任意質問済み。未回答でも作業を進める。
- 大学課程は分野により異なるため、記号の名前・意味・入力例・引数型・出力型・定義域・計算方式・受入例・ヘルプを公開目録で明示する。目録外の記号も名前と意味を定義できる数式記号として保持する。未知記号を既存定数や掛け算へ黙って変換しない。
- 文字が表示できることだけを「使用可能」としない。演算を表す項目は計算と通常座標/関数での利用まで実証する。集合・命題・記号定義など数値を直接表さない項目は、その型を保持して条件・範囲・成分抽出へ接続する。
- 任意の式に必ず閉形式解や一意な数値解が存在するとは扱わない。未評価、発散、定義域外、複数解、未指定条件、資源上限を独立した結果として表示する。未評価の演算が残ることと未実装の演算を別に記録する。
- 既存15件のうちADD-2を共通入力基盤とし、下記12件を追加する。全体553→**580件**、将来115件は維持。確定449/580=77.4%、既存受入候補503/580=86.7%。前の568件案は大学数学への拡大前の数。本計画・関数作図計画・要件・進捗台帳を同じ変更で更新する。
- 数学基盤13件（ADD-2、17〜28）を1つの実装単位、関数作図14件（ADD-3〜16）を次の実装単位として、双方とも10件以上の原タスクを完成させmainへ着地させる。ファイル数や検査件数を完成タスクへ数えない。

## 2. 入力と互換性

1. 共通の数式エディターを座標欄・関数欄・係数欄・範囲欄から開く。通常の短い式は直接入力でき、分数/積分/行列は構造を持つ入力を選べる。Unicode、通常テキスト、LaTeXの貼付と表示を扱う。
2. 軸X/Y/Z、媒介T/U/V、係数、定数、束縛変数を型付きの名前解決で保持する。係数はパレットから挿入する`coef("名前")`相当の専用ノード。表示も「係数: 名前」を識別でき、係数を[名前]と記す初期案は行列/区間と衝突するので採用しない。
3. X/Y/Zの英字、添字、ギリシャ文字、虚数i、定数e、Euler数、係数名log/sinと演算名を混同しない。範囲の総和の添字は外部の係数を上書きしない。コピー/改名/保存でもノードの役割を維持する。
4. 既存式はlegacy形式を保持する。新たな予約語の追加で既存のパラメータ名sin/log等を拒否しない。編集していない旧式の評価値、単位、rad()の従来意味、Undoを変えない。
5. 新しい数式形式にはschema/構文/数学規約の版、原入力、明示的な角度単位、型付きAST、係数参照を保存する。エンジン固有JSONだけを永続形式の正本にせず、許可した独自ASTへ検証・変換する。
6. 暗黙積は数式入力で構造として表示したものだけ採用。係数名と軸XYZの連結を勝手に分割しない。曖昧な縦棒や逆関数は候補/意味をその場で示す。IME変換中のEnter、上下添字移動、Tab/ShiftTab、Esc、読み上げとキーボード操作を受入に含める。
7. ベクトルや複素数を扱った式でも結果が有限実数へ帰着すれば座標に使える。結果がベクトルならXYZへの割当を選べ、複素数ならRe/Im/abs/arg、集合なら条件または候補を明示して選ぶ。入力中の選択が無い限り自動変換しない。

## 3. 実装方式と資源

- MathLive 0.110.0とCompute Engine 0.128.6の公開配布物を、npm registryのSHA-512一致を検証して隔離した場所で調査した。両方の同梱MIT本文を確認済み。まだプロジェクトへ依存を追加していない。
- MathLiveの既定依存はCompute Engine 0.58.0であり、最新版のAPI確認結果をそのまま内蔵エンジンの能力と扱わない。エディターはLaTeX/構造入力を担当し、計算は明示固定したWorker内エンジンへ渡す。二重搭載と自動CDN取得を避け、字体・音声等の資産もローカル/オフラインで完結させる。
- 実APIで10例を実行し、算術509、三角/対数4.5、複素絶対値5、総和385、総積120、微分3x²、積分1/3、行列式−2、極限1、共通集合{2,3}を確認した。これだけで網羅完了とはしない。例と生の結果は`math-candidates/api-study.json`。
- 追加のJIT無効実証では、NIntegrateの公式tuple表記が未評価のまま、旧来の平坦な引数ではsin(x²)の0〜1積分が0.3117となり、独立級数の0.3102683017233811018…に一致しなかった。NLimit(sin(x)/x,0)もNaNとなった。結果を採用済みにしない。数値積分/数値極限はこの既定経路へ委ねず、定数の記号評価と独立した決定的数値アルゴリズムを組み合わせる。生の失敗は`csp-study.json`/`quadrature-study.json`へ保持し、通常検査へ独立オラクルとJIT無効の回帰を追加する。
- 解析前に入力長・トークン/入れ子・数値桁数を制限し、外部評価ではWorkerを期限で破棄できるようにする。ASTは再帰ではなく反復走査で個数/深さ/演算/参照を検証する。検証前にcanonical化や評価を行わない。
- 書換・代入・宣言・外部アクセス・時刻・乱数・実行コード・無制限ループを入力式から許可しない。束縛変数を持つ純粋な積分/総和の構造と命令Blockを区別する。外部ホストへeval/Function/compileのJavaScriptを渡さない。
- エンジンは数値積分等を内部で自動コンパイルする経路があるため、生成直後に`ce.jit = 'off'`を必ず設定する。0.128.6の公開API`withTimeLimit`は同期コールバックの間だけ有効。asyncを渡さず、外側のWorker終了タイマーと併用する。MathLive側は`MathfieldElement.computeEngine = null`とし、既定の旧エンジンを計算に使わない。
- 数値は既存の高精度入力契約を維持する。CAD境界でのみ有限doubleへ変換。型、誤差推定、収束、単位、分岐、数値解の探索範囲を結果へ含める。
- 座標の1評価と曲面の数万点評価は計算計画を分ける。式を1回検証し、X/Y/Z/T/U/Vの変わる部分だけを評価する。定数の積分や行列分解を標本ごとに再実行しない。純粋な式のみキャッシュ可能。
- 検索/パレット/対応表/説明書は共通目録を使う。未実装演算の目録状態を対応済みにできない受入ID照合を設け、表示できるだけの記号を完成扱いする再発を防ぐ。
