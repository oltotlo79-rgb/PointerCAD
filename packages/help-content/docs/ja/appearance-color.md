# 色と材質を選ぶ

立体全体、または面 1 枚に、色や材質(鉄板・アルミ・木材など)を割り当てます。

## 面や立体を選ぶ

1. ツールバーの「外観」を押します。
2. 色を付けたい**面**をクリックします。面ではなく**立体まるごと**に付けたいときは、キーボードの `4` を押してから立体をクリックします(画面いちばん下の帯で、いま選べるものが「立体」に変わったことを確かめられます)。
3. 右の「プロパティ」に「外観」という節が出るので、ここで色や材質を決めます。

## 材質を選ぶ(11 種の一覧と見え方)

「材質」の一覧から、次のどれかを選べます。選んだ瞬間に、色・柄・光沢・粗さ・透過率がまとめて決まります。

| 名前 | 見え方 |
|---|---|
| 既定 | 灰色の、艶を抑えた面(色や材質を付ける前の見え方) |
| 鉄板 | 灰色で光沢のある金属 |
| 縞鋼板 | 鉄板に縞模様が付いたもの |
| エキスパンドメタル | 鉄板に網目模様が付いたもの(穴が空いて見えます) |
| アルミ | 明るい灰色の金属 |
| ステンレス | さらに明るく、艶のある金属 |
| プラスチック | 色を自由に選べる、艶を抑えた面 |
| 木材 | 木目の模様が付き、樹種を選べます |
| 鏡 | 周りの景色が映り込みます |
| ガラス | 向こう側が透けて見えます |
| 自分で決める | 色・柄・光沢・粗さ・透過率を個別に決めた状態(数値を 1 つでも打ち直すと、自動でここに変わります) |

## 色を変える(見本と数値)

「色」の見本(8 色)をクリックするか、16 進の欄(例: `#ff8800`)に数値を入れると、色を変えられます。どの材質を選んでいても、色だけ別に変えられます。

## 光沢と粗さ

「光沢」「粗さ」はそれぞれ 0〜100 の数値(式も打てます)で調整します。光沢を上げるほど金属的に、粗さを上げるほどつや消しに見えます。

## 割り当てを外す・すべて戻す

- 「この割り当てを外す」で、選んでいるものの色・材質だけを既定に戻します。
- 「すべて既定に戻す」で、文書全体の色・材質をまとめて既定に戻します。
- 元に戻す(Ctrl+Z)で、色・材質の変更も取り消せます。

## 形を大きく変えると色が外れることがある

押し出しの距離を変える程度であれば、面に付けた色はそのまま残ります。ただし、フィーチャーの種類を変えるなど形を大きく作り替えると、どの面に色を付けていたか分からなくなることがあります。そのときは画面下の帯に「色を付けた面が n か所見つかりません。形が変わったため、選び直してください。」と出て、その面はいったん既定の色に戻ります。プロパティの「見つからない割り当て」の一覧からも、残った割り当てを外せます。

## うまくいかないとき

「外観」を押しても色が変わらないとき、または画面下の帯に理由が出たときは、次を確かめてください。

| 出る文 | 直し方 |
|---|---|
| 色や材質を付けるものが選ばれていません。 | 面か立体をクリックしてから、もう一度選びます |
| この立体には 8 種類までしか違う見た目を割り当てられません。 | 同じ立体に付ける色・材質の種類を減らします |
| 見た目の割り当てが多すぎます。まとめてください。 | 同じ見た目の面をまとめるか、割り当てる面の数を減らします |
| 透過率・光沢・粗さは 0 から 100 の間で指定してください。 | 入れた数値を 0〜100 の範囲に直します |
