# 読み込む(ほかのソフトの形を取り込む)

ほかの CAD やスライサーで作った形を、この部品の中へ取り込めます。

## 読み込みかた

いちばん上の**ファイル**を押して、一覧の中の**読み込む**を選びます。ファイルを選ぶ窓が開くので、取り込みたいファイルを選んでください。

読める形式は 6 つです。

| 形式 | ファイルの終わり | 取り込んだあとにできること |
|---|---|---|
| STEP | `.step` `.stp` | 穴あけ・面取り・組み合わせができる |
| STL | `.stl` | 見る・測る・書き出す |
| OBJ | `.obj` | 見る・測る・書き出す |
| 3MF | `.3mf` | 見る・測る・書き出す |
| glTF | `.glb` `.gltf` | 見る・測る・書き出す |
| DXF | `.dxf` | 図形としてスケッチに入る([DXF を読み書きする](dxf.md)) |

読み込んだ形は、履歴のいちばん下に**読み込んだ形**という段として並びます。名前を書き換えたり、消したりできます。

## STEP とそれ以外の違い

**STEP で取り込んだ形は、この中で作った立体と同じように扱えます。** 穴をあける、角を丸める、ほかの立体と足したり引いたりする、といったことができます。

**STL・OBJ・3MF・glTF で取り込んだ形は、細かい三角形の集まりです。** 見る・測る・別の形式へ書き出すことはできますが、**穴あけや面取りはできません。** 選んで道具を押すと、「読み込んだ三角形の形には、穴あけや面取りはできません。」と出ます。

三角形の集まりから丸みのある面を作り直すことはしません。作り直すと面の数が三角形の数だけできてしまい、そのあとの加工がまともに動かないためです。

## 単位

**STEP・3MF・glTF は、ファイルの中に単位が書いてあります。** インチで作られたファイルでも、正しい大きさで開きます。

**STL と OBJ には単位がありません。** そのため、読み込むときに「このファイルの単位を選んでください。」と聞かれます。**ミリメートル**か**インチ**を選んでください。取り違えると、25.4 倍または 1/25.4 倍の大きさで入ります。

選んだ単位は、あとからプロパティの「読み込んだ形」で確かめられます。

## 取り込んだ後の見え方

読み込んだ形は、**ファイルに書いてあった位置のまま**置かれます。原点へ寄せることはしません。組み立ての部品のように置き場所に意味があるファイルを壊さないためです。

取り込んだ直後は、その形が画面いっぱいに映るように視点が合います。

色は、この中の既定の色になります。ファイルに入っていた色は使いません。色は[色と材質を選ぶ](appearance-color.md)であとから付けられます。

## プロパティで確かめられること

履歴の「読み込んだ形」の段を選ぶと、右のプロパティに次のことが出ます。

- 元のファイルの名前
- 形式(STEP・STL・OBJ・3MF・glTF)
- 取り込んだときの単位
- 三角形の数(三角形の形のとき)、または中身のある立体か面だけかの別
- ファイルの大きさ

寸法を直す欄はありません。読み込んだ形には作り方の履歴が無いためです。大きさを変えたいときは、[立体の形を変える](shape-edit.md)の拡大縮小を使ってください。

## 保存すると一緒に残る

読み込んだ形は、**この部品のファイルの中に一緒に入ります。** 元のファイルを消したり移動したりしても、部品は開けます。人に部品ファイルを渡しても、形はそのまま届きます。

そのぶん部品のファイルは大きくなります。大きな三角形の形をいくつも取り込むと、保存に少し時間がかかります。

## 読めなかったとき

読めなかったときは、下の帯に理由が出ます。**いま開いている部品は変わりません。**

| 出る言葉 | 意味 |
|---|---|
| このファイルを読めませんでした。ファイルが壊れているか、対応していない形式です。 | 中身が壊れているか、この形式ではありません。 |
| このファイルには形が入っていません。 | 開けたが、中に立体がありませんでした。 |
| この形には面がありません。 | 三角形が 1 枚も入っていませんでした。 |
| この形は大きすぎて開けません。 | 三角形が多すぎます。元のソフトで粗くしてから書き出し直してください。 |
