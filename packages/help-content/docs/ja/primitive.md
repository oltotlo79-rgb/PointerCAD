# 球・箱・円柱・円錐・トーラスを置く

面をかかなくても、はじめから決まった形をそのまま置けます。上の「ソリッド」の区画にある「作る」のボタンを押すと一覧が開き、下のほうに「球」「箱」「円柱」「円錐」「トーラス」が並んでいます。

どれも**何も選ばずに押して、そのまま Enter を押すだけ**で置けます。置いたあとで大きさも位置も直せます。

## 置き方

1. 「ソリッド」の「作る」を押して、一覧から形を選びます。
2. 小さな入力欄が出ます。大きさを入れます。
3. Enter を押すか「決定」を押します。

数を入れずにそのまま Enter を押すと、次の大きさで置きます。

| 形 | 入れる数 | 何も入れなかったとき |
|---|---|---|
| 球 | 半径 | 半径 10 mm |
| 箱 | X の長さ・Y の長さ・Z の長さ | 20 × 20 × 20 mm |
| 円柱 | 半径・高さ | 半径 10 mm、高さ 20 mm |
| 円錐 | 下の半径・上の半径・高さ | 下 10 mm、上 0 mm、高さ 20 mm |
| トーラス | 主半径・管の半径 | 主半径 20 mm、管の半径 5 mm |

`5*2` のような式も書けます。あとから直すときも式のまま残ります。

やめたいときは Esc を押します。何も置かれません。

## 中心をどこにするか

入力欄の中に位置の欄はありません。**中心は「置く前に何を選んでいたか」で決まります。**

- **何も選んでいないとき**: 原点(X・Y・Z が 0 の点)に置きます。あとからプロパティで座標を直せます。
- **立体の角(頂点)を選んでいるとき**: その角が中心になります。角を選ぶには、下の帯の「選ぶもの」を「頂点」にしてから角をクリックします(`1` キーでも切り替わります)。
- **かいた点を選んでいるとき**: その点が中心になります。先に「点」の道具で点をかき、「選択」でその点をクリックしてから形のボタンを押します。

**円柱と円錐だけは「底面の中心」を指します。** 球・箱・トーラスは形のまんなかです。円柱と円錐は、高さを変えても底の面が動かないほうが、押し出しと同じ感覚で使えるためです。

角を中心にして置いても、角を貸した立体はそのまま残ります。消えたり組み合わさったりはしません。

## 向きを決める

入力欄の下に「回転軸」があり、X・Y・Z から選べます。はじめは Z(縦の軸)です。

- **円柱・円錐**: 底面の中心から、選んだ軸の向きへ伸びます。
- **箱**: 選んだ軸が箱の高さの向きになります。
- **球・トーラス**: 球は向きを変えても見た目が変わりません。トーラスは輪の面の向きが変わります。

線分を選んでから形のボタンを押すと、「選んだ線分」も軸の候補に加わります。

## あとから直す

置いた形は自動的に選ばれた状態になり、道具は「選択」に戻ります。左の「モデルブラウザ」に「球1」「箱1」のように並びます。

行をクリックすると、右のプロパティに次の 3 つが出ます。

- **基本形状**: 大きさの欄。数を書き換えるとその場で形が変わります。式も書けます。
- **向き**: X・Y・Z のボタン。
- **中心**: 座標で置いたときは X・Y・Z の 3 欄が出て、書き換えると形が動きます。点や角で置いたときは、そのもとの名前が出ます。

## うまくいかないとき

下の帯に理由が出ます。置く前に赤くなるので、直してから Enter を押してください。

| 出る文 | 直し方 |
|---|---|
| 半径は 0 より大きい数にしてください。 | 半径に 0 や負の数が入っています |
| 箱の X・Y・Z の長さは 0 より大きい数にしてください。 | 3 つのどれかが 0 以下です |
| 円柱の半径と高さは 0 より大きい数にしてください。 | 半径か高さが 0 以下です |
| 円錐の半径は、どちらか一方を 0 より大きくしてください。 | 上下とも 0 では形になりません |
| 円錐の上下の半径が同じです。円柱を使ってください。 | 同じ太さのままなら、それは円柱です |
| トーラスの管の半径は、中心までの半径より小さくしてください。 | 管が太すぎて、まんなかの穴がふさがっています |
| 中心にする点が見つかりません。点を選び直してください。 | 中心にした点を消したときに出ます。プロパティで置き直してください |
| 中心にする頂点が見つかりません。形が大きく変わったため、選び直してください。 | 角を借りたもとの立体を大きく作り替えると出ます。角を選び直してください |

**円錐の上の半径は 0 のままでかまいません。** 0 なら先のとがった円錐、0 より大きい数を入れると上が平らな円錐(円錐台)になります。

置いたものは、和・差・積で他の立体と組み合わせたり、穴をあけたり角を丸めたりできます。
