# 原点を置き直す

いま作っているものの **原点(0, 0, 0)** を、好きな点へ置き直せます。「部品の角を原点にしたい」「穴の中心を基準に寸法を測りたい」というときに使います。

原点を置き直すと、選んだ点の座標が (0, 0, 0) になり、**ほかのものはすべて同じだけ一緒に動きます。** 部品の形も、部品どうしの位置関係も変わりません。動くのは「どこを 0 と呼ぶか」だけです。

## やり方

方法は 2 つあります。どちらでも同じことが起きます。

### モデルブラウザから

1. 左のモデルブラウザで、原点にしたい **点** の行を右クリックします(行の右にある「⋮」を押しても同じです)。
2. 出てきた一覧の「ここを原点にする」を押します。

この一覧に出るのは、スケッチの点と、基準の点の行だけです。線や円弧、面、立体の行には出ません。

### プロパティから

1. 原点にしたい点をクリックして選びます。
2. 右のプロパティのいちばん下に「原点」の欄が出るので、「ここを原点にする」を押します。

**立体の頂点はこちらから選びます。** 立体の頂点をクリックすると、ボタンが「この頂点を原点にする」に変わります。

## 何が起きるか

置き直したあと、画面の下の帯に「原点を (…) から移しました。」と出ます。括弧の中が、もとの原点がいまどこにあるか(= 動かした量)です。

**入れた式はそのまま残ります。** たとえば、ある点の X に `10 + π/2` と入れてその点を原点にすると、X に `3` と入れてあった別の点は `3 - (10 + π/2)` になります。小数に丸められることはありません。整数どうしのように、きっちり計算できるときだけ 1 つの数にまとまります。

**立体の頂点を原点にしたときは、式ではなく数値になります。** 頂点の位置は形から計算されたもので、もとになる式がないためです。桁は落とさないので位置はぴったり合いますが、あとから式を直したいときは、先に基準の点を作ってその点を原点にしてください。座標を直接入れて原点にしたいときも同じで、その座標の基準点を作ってから原点にします。

**基準になるものを決めてある位置は、そのまま追従します。** 「直前の点から +10」のような相対の位置や、立体の頂点にくっつけた点、自分で作った作業平面の上にかいたものは、基準のほうが動くので自動的についてきます。書き換えられるのは、原点からの絶対の位置と、基準の 3 面(XY・XZ・YZ)から離して作った作業平面の距離です。

**見えない作業平面が増えることがあります。** 基準の 3 面の上にかいたスケッチを、面から浮く向きへ動かすときは、その面から離した作業平面を作ってスケッチを載せ替えます。モデルブラウザの「基準」に「補助」の札が付いた行として出ますが、画面には出ません。消すとスケッチの位置が決まらなくなるので、そのままにしておいてください。

## 元に戻す

**元に戻す(Ctrl+Z)を 1 回押せば、置き直す前に戻ります。** 履歴に新しい行が増えることはありません。原点を置き直しても、作った順番や中身の一覧は変わりません。

## うまくいかないときは

- 「ここを原点にする」が出ない — 点以外(線・円弧・面・立体そのもの)を選んでいます。点を選び直してください。点をたくさん選んでいるときも出ません。1 つだけ選んでください。
- 「編集できませんでした: 選んだ点の位置がまだ計算できていないので、原点にできません。」— その点の位置が決まっていません。式が正しく入っているか、基準にしているものが消えていないかを確かめてください。
