#### 2026-09-07 の訂正 §2.2（R9-3）

Web の行は「加工ソフトを開く」「保存したファイルを開いた先で選ぶ」と表示し、自動転送されたように見せない。外部 URL は許可した `https` の固定表だけから選ぶ。desktop の `shell.openPath` は renderer から任意パスを受けず、**直前の書き出し成功に対する不透明 token**だけを受け、main が記憶したパスへ解決する。token は成功ごとに更新し、別の成功・失敗・期限切れでは再利用できない。互換性確認は統括が配布候補の形式と相手版で行う。

- **押さなくても書き出しは完了している。** 案内は閉じられ、閉じても保存したファイルは残る。
- 外部ソフトの手順(Fusion 360 無料版で STEP を読んで 2.5D の加工パスを作る / FreeCAD Path で加工パスを作る)は**ヘルプ `cam.md` にだけ書く**(アプリの中に他社ソフトの操作を埋め込まない)。

### 2.3 簡易の強度計算(FR-1112)

**3 つの型だけを扱う。** どれも「寸法と力を入れる → 応力とたわみが出る → 材料の許容できる値と比べる」の同じ流れにする(NFR-UX-1)。

| 型 | 入れるもの | 出るもの | 使う公式 |
|---|---|---|---|
| 梁の曲げ | 支え方(片持ち / 両端支持)・長さ `L`・力 `F`・断面(長方形 `b×h` / 円 `d` / 円筒 `d×t`) | 曲げモーメント `M`、断面係数 `Z`、曲げ応力 `σ = M / Z`、たわみ `δ` | 片持ち: `M = F·L`、`δ = F·L³ / (3·E·I)`。両端支持(中央 1 点): `M = F·L / 4`、`δ = F·L³ / (48·E·I)` |
| 軸のねじり | 直径 `d`(中空なら内径 `d₁`)・長さ `L`・トルク `T` | 極断面係数 `Zp`、せん断応力 `τ = T / Zp`、ねじれ角 `θ = T·L / (G·Ip)` | 中実: `Zp = π·d³ / 16`、`Ip = π·d⁴ / 32` |
| ボルトの引張 | 呼び径(M2〜M64。**P3 のねじの規格の表を使う**)・軸力 `F` | 有効断面積 `As`、引張応力 `σ = F / As` | `As` はねじの規格の表から引く → **前提誤り。2026-09-07 の訂正 §2.3 参照** |

**断面の性質(長方形 `b×h`):** `I = b·h³ / 12`、`Z = b·h² / 6`。**円 `d`:** `I = π·d⁴ / 64`、`Z = π·d³ / 32`。

**材料と余裕(§0.2 の推奨案の場合):**

- 表が持つのは **降伏点 `σy`・引張強さ `σt`・縦弾性係数 `E`・横弾性係数 `G`** の 4 つ(規格から引ける値)。
- **許容応力 = `σy` ÷ 安全率**(安全率は既定 3、式で変えられる)。**余裕(安全率の実際)= 許容応力 ÷ 求めた応力。** → **用語の旧記述。2026-09-07 の訂正 §2.3 参照。**
- 材料の候補(**規格番号と値は §0.2 で統括が確定する。下の値は候補であり、担当は勝手に確定しない**):

| id | 材料(候補) | 降伏点 `σy` (MPa) | 引張強さ `σt` (MPa) | `E` (MPa) | `G` (MPa) | 出典(**要確認**) |
|---|---|---|---|---|---|---|
| `steel` | 一般構造用圧延鋼材 SS400 | 245 | 400 | 205000 | 79000 | JIS G 3101 |
| `carbon-steel` | 機械構造用炭素鋼 S45C(焼ならし) | 345 | 570 | 205000 | 79000 | JIS G 4051 |
| `stainless` | ステンレス鋼 SUS304 | 205 | 520 | 193000 | 74000 | JIS G 4305 |
| `aluminum` | アルミニウム合金 A5052-H34 | 180 | 235 | 70000 | 26000 | JIS H 4000 |
| `custom` | 任意(利用者が式で入れる) | — | — | — | — | — |

- **答えには使った式と当てはめた数値を並べて出す**(要件 FR-1112)。例:「曲げモーメント M = F × L = 10 N × 100 mm = 1000 N·mm」。**内部用語は 1 語も出さない**が、`M` / `Z` / `σ` のような**製図と教科書の記号は利用者の言葉**として使ってよい。
- **形状から断面を自動で拾わない**(要件 §4.13b の注記)。断面の形と寸法は利用者が選んで入れる。**測定(FR-1102)で測った値を手で写せる**ようにする(測定の結果は画面に残っている)。
- **有限要素法・応力の分布図・座屈・疲労は扱わない。** より詳しく調べたい人のために、**ヘルプ `strength.md` に外部の解析ソフト(FreeCAD FEM / CalculiX)へ STEP で渡す手順**を書く。

#### 2026-09-07 の訂正 §2.3（R9-2・R3-5）

返却を、応力 / 変位、採用基準、指定安全率 `n`、実際安全率、余裕率に分ける。`σy/σ` が実際安全率、`(σy/n)/σ` が指定安全率 `n` に対する余裕率であり、両者を混同しない。ねじりは von Mises を採る場合、review.md の記法どおり `τ_allow=σy/(sqrt(3)·n)`、同値な表記で `τ_allow = σy/(√3·n)` とする（または採用したせん断許容表を使う）。単位は `N / mm / MPa / N·mm / rad` に統一し、度は表示時だけにする。

中空円は外径 `d` と内径 `d₁` の4乗差で `I / Ip` を求め、`0<t<d/2` を検証する。既存の `metricThread.ts` は呼び径とピッチだけで、`As` を持たないため、`tensileStressArea(d, p)` を追加する。正本を規格の `As` 表にするか `π/4·(d−0.9382p)²` にするかは統括が原典と照合して固定し、呼び + ピッチ / 系列をキーにする。

材料 ID は規格 / 鋼種 / 調質 / 製品形状 / 厚さ範囲 / 温度条件を持ち、`E / G` と強度の出典を分けて記録する。上の候補値を確認済み規格値と表示しない。タスク2は補修 R-8（パラメータ間の任意精度と `QuantityKind`）完了後にだけ着手する。

### 2.4 DWG の受け渡しの案内(FR-817)

### 2.5 曲面の強化(FR-435)

#### 2026-09-07 の訂正 §2.5（R9-1）

旧タスク5を、5a スプライン断面、5b 案内線、5c なめらかさ、の三つの能力実証へ分ける。5a は閉輪郭 / 穴 / 異なる辺数 / twist を、rules/06 10.16 に従う保護された wire 経路で実証する。5b は `MakePipeShell` の補助 spine について `CurvilinearEquivalence` と `KeepContact` の意味、経路と案内線の対応区間、退化・接触不能の検査を固定する。5c は「ロフト自身を滑らかにする」なら現案 `SetSmoothing / SetContinuity` を検証し、「隣接面へ G1 接続」なら `BRepFill_Filling / GeomPlate_BuildPlateSurface` を別に実証する。どちらの意味かは利用者の判断待ちで、`SetSmoothing(true)` を「選んだ面と滑らかにつながる」と表示してはいけない。G2 は範囲外。

**(a) スプライン断面のロフト**

- `ThruSectionSpec` の `kind: 'curves'` は既に `CurveSpec[]`(`SplineCurveSpec` を含む)を取る。**kernel は変えずに済む見込み**で、変えるのは **ui がロフトの断面として受け付ける要素の種類**である。
- 担当は手順 1 で「スプラインの輪郭を渡したロフトが実際に成り立つか」を実測する。**成り立たなければ、そこで止めて統括へ報告する**(値や期待を書き換えない)。

**(b) 案内線つきのスイープ**

- `SweepInput` に **`guide`**(案内線。`CurveSpec[]`、省略できる)を 1 欄足す。省略時はこれまでどおり。
- 案内線があるときは `SetMode_5(AuxiliarySpine, CurvilinearEquivalence, KeepContact)` を使う。**`BRepFill_TypeOfContact` の列挙は述語ガード 1 か所で絞る**(§0.4)。**既存の `SetMode_1` / `SetMode_3` の経路は 1 行も変えない。**
- **案内線は経路と交わっていなくてよいが、経路と同じ向きに伸びている必要がある。** 成り立たないときは日本語の理由で断る(NFR-RE-1、FR-504)。

**(c) つなぎ目のなめらかさ**

- `ThruSectionsStepSpec` に **`smooth: boolean`** を 1 欄足す(既定 `false` = これまでどおり)。`true` のとき `SetSmoothing(true)` を呼ぶ。
- **`SetSmoothing` だけで接線がつながるかを実測する**(§0.4、実測項目 5)。つながらなければ `SetContinuity(GeomAbs_C1)` が要り、**述語ガードがもう 1 か所増える**(承認済みの範囲内で行う)。
- **`ruled: true`(罫線面)のときは `smooth` を使わない**(まっすぐ結ぶ機能なので意味を持たない)。ui は罫線面のときになめらかさの欄を出さない。

**⚠️ 鍵(キャッシュ)への影響:** `smooth` と `guide` は**形を変える指定**なので、**`packages/model/src/part/cacheKey.ts` の鍵の材料に必ず含める。** 含めないと、指定を変えても古い形がキャッシュから返る(P5・P6 で繰り返し確認された規律。`ThruSectionSpec` の `faceQuery` の注釈と同じ理由)。

### 2.6 性能(NFR-PF)

## 4. 共通の作業規約(全タスク共通)

- **gitへ書き込まない。** 変更したファイルの一覧と検査結果を統括へ報告する(`rules/01-役割と委譲.md` §1)。**`git stash` を含め、作業ツリーを退避・復元する書き込み操作を一切しない**(`rules/06` 10.4)。
- **Agent ツールで別の担当を起こさない**(検査も自分で前景で実行する。`rules/06` 10.6)。**報告には必ず「Agent ツールの使用: なし」の 1 行を含める。**
- **依存を勝手に足さない。** P11b で追加する外部依存は **0 件**(§1)。必要になったら**作業を止めて統括へ提案**する(`rules/02-禁止事項.md`)。

- **テストの期待値を緩めない。** 実測が期待値と違ったら、値を書き換えるのではなく**実測値と自分で検算した値を統括へ報告**する。**性能の上限値(500ms / 5000ms / 1000ms、および P6 §2.17 の 10 件、§2.6 の 3 件)も緩めない。**
- **ブラウザの窓・Electron・開発サーバーを起動しない。** ヘッドレスのテスト実行(Vitest、Playwright の headless)は可。**外部サイトを実際に開くこと・既定のアプリで開くことの実動作は統括が §5 で確かめる。**
