## 新しくなったこと

### 日本の鋼材の規格と材質から選んで置けるようになった

アセンブリの規格部品の種類「形鋼」で、鋼種(SS400・S45C・SGP)を先に選び、その鋼種で扱う断面と呼び寸法だけから選んで置けるようになりました。規格に無い鋼種と断面の組み合わせは選べません。[規格部品を置く](../../packages/help-content/docs/ja/standard-parts.md#鋼材を置く)

- 材質: SS400(JIS G 3101)は熱間圧延材、S45C(JIS G 4051)はみがき棒鋼と熱間圧延材、SGP(JIS G 3452)は黒管と白管(亜鉛めっき)です。SS400とS45Cは熱処理を指定しません(熱処理条件未指定)。
- 断面: 平鋼(SS400 132組・S45C 119組)、丸鋼(SS400 44径・S45C 39径)、等辺山形鋼・溝形鋼・H形鋼(SS400 17・11・49寸法)、配管用鋼管(SGP 6A〜500Aの黒管・白管 各24サイズ)。候補の多い平鋼は、厚さを選んでから幅を選べます。
- 長さ: 1〜12,000 mmの数または式で指定します。
- 注記: 材料規格と寸法規格の番号:版(例 JIS G 3101:2024)と確認の程度、供給の条件、形の作り方、資料に記載された標準長さ、寸法の資料を示します。
- 鋼材切断リスト: 置いた鋼材を、部分組立の内部も含めて鋼種・呼び寸法・長さごとに集計し、出典と版を含む30列のCSVに保存できます。
- 断り: 保存した組み立ての鋼材が組めないとき(扱わない鋼種と断面の組み合わせ、一覧に無い呼び寸法、書き換えられた指定、新しい版のカタログなど)は、その部品を作らずに理由と規格の箇条を示します。
- 制限: 規格の版は日本鉄鋼連盟が公開する改正原案で確かめたもので、規格票(公布された本文)とは照合していません(JIS G 3123は未確認)。製造公差・ねじ・ソケット・めっきの厚さは形に入りません。在庫・材料証明・強度・耐圧の保証ではなく、部品表の材質の欄は鋼種によらず「鋼(SS400)」と出ます。
