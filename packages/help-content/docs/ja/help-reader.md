# ヘルプを探す・説明の続きを読んで戻る

道具を操作しているときや数値・関数を入力しているときは、**F1** を押すと、その操作に対応した説明が開きます。各画面のヘルプボタンからも開けます。入力途中の式や指定範囲を残したまま説明を読めます。

## 目的の操作を探す

目次は操作の種類ごとに分かれています。作図、図面、板金など、目的に合う見出しから説明を選べます。

左側の **{{ui:help.search}}** に操作名や知りたい内容を入力します。たとえば「曲面 範囲」のように空白で語を区切ると、両方の語を含む説明を探せます。ひらがな・カタカナ、全角・半角の違いをそろえて検索します。検索は端末の中で行い、検索語を外部へ送りません。

候補を押すと本文が右側に表示されます。検索欄を空にすると全項目の目次へ戻ります。本文の取得に失敗した場合は、案内にある **{{ui:help.retry}}** を押してください。一部の章を取得できなかった検索結果には、その旨が表示されます。

## 説明の続きを読み、元の場所へ戻る

本文内の関連項目を押すと、その説明へ移ります。画面上部の **{{ui:help.back}}** で前の章と読んでいた位置へ戻れます。**{{ui:help.forward}}** は、戻る前に開いていた項目へ進みます。戻った後に別の項目を選んだ場合は、新しく選んだ順序に沿って移動します。

本文の末尾にある **{{ui:help.previousChapter}}** と **{{ui:help.nextChapter}}** で、目次の前後の説明を順番に読めます。最初・最後の項目には、それ以上の移動先を表示しません。閲覧履歴は、このヘルプ画面を開いている間だけ保持します。

## 作業へ戻る

**Esc** または **{{ui:help.close}}** でヘルプを閉じます。元の入力欄が残っている場合は、そこへ焦点が戻り、続きを入力できます。ヘルプ内の戻る・進むは説明の閲覧に使います。作図のUndo・Redoや文書の保存状態は変更しません。

## ボタンや入力欄の短い説明を読む

マウスを重ねると、ボタンや入力欄の短い説明を読めます。Tab・Shift+Tabや矢印キーで移動したときも、同じ説明が操作対象の近くに表示されます。割り当てたキーがボタンの説明にある場合は、そのキーも表示します。説明は入力欄やボタンを操作する邪魔にならず、マウスで操作を始めると消えます。

詳しい手順は、そのままF1で開けます。Escは通常どおり現在の入力や画面を閉じる操作として働き、短い説明も消えます。数値の途中入力や図面は、説明を表示しただけでは変わりません。
