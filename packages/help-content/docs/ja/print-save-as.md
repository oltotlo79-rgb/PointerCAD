# 印刷する・別名で保存する

画面のいちばん上の **ファイル** を押すと一覧が開きます。ここでは、その中の **印刷**・**名前を付けて保存**・**最近使ったファイル** の 3 つを説明します。

## 印刷する

一覧の **印刷** を選ぶと、**いま画面に見えている向きのまま** 1 枚に印刷されます。回してから押せば、そのときの見え方がそのまま紙になります。

用紙の大きさ・向き・部数は、続けて出てくる印刷の窓で決めてください。

紙は必ず **白い下地** に印刷されます。画面を暗い見た目にしていても、紙が黒くなることはありません。

紙の上のほうには、部品の名前と印刷した日時が入ります。

図面としての印刷(枠や表題欄の入ったもの)は、まだできません。いまできるのは、見えているものを 1 枚に写すところまでです。

印刷できない環境では **この環境では印刷できません。** と画面のいちばん下に出ます。3D の絵がまだ出ていないうちに押したときは **印刷する絵を作れませんでした。** と出るので、少し待ってからもう一度押してください。

## 別名で保存する

一覧の **名前を付けて保存** を選ぶと、いまの部品を別の名前で保存できます。

- **元のファイルは変わりません。** 保存した時点までの元のファイルはそのまま残ります。
- 以後の「保存」は、**新しい名前のファイル** へ書き込みます。
- 途中でやめたときは、名前も保存先も変わりません。

同じことは、キーボードの **Ctrl+Shift+S** でも、保存のボタンを **Shift を押しながら** 押してもできます。作りかけを別名で取っておいてから続きを試したいときに使ってください。

## 最近使ったファイル

一覧のいちばん下に、最近 **開いた** ファイルと **保存した** ファイルの名前が、新しい順に **10 件まで** 並びます。11 件目が入ると、いちばん古いものが落ちます。同じ名前は 1 行にまとまり、いちばん新しい時刻で上へ来ます。

名前を選ぶと、**ファイルを選ぶ窓が開きます。** その場ですぐ開くのではありません。覚えているのは名前だけで、**どこに置いてあるかまでは覚えない** ためです。窓が出たら、同じ名前のファイルを探して選んでください。

一度も開いたり保存したりしていないときは、この行は出ません。
