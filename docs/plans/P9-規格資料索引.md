## 実装へ渡す照合表

P9-1で各行を、型付き検証規則・正例・拒否例・画面/保存/出力の検査へ接続する。以下は条項の索引であり、未実装の入力規則を合格とする表ではない。

|---|---|

| 平行度 / 直角度 / 傾斜度 | 18.9 / 18.10 / 18.11 |
| 位置度 / 同軸度 / 対称度 | 18.12 / 18.13 / 18.14 |

データムの要否を特性名だけで一律に決めず、輪郭度の関連の有無や位置度の指定を区別する。共通データムと優先順付きの複数データムも異なる意味として照合する。枠の文字高・余白等のアプリ初期値を規格必須値と呼ばない。
