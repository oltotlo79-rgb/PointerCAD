# かいたものを直す

一度かいたものは、あとから何度でも直せます。

## 選ぶ

左の「モデルブラウザ」に、かいたものが上から順に並びます。行をクリックすると選べます。3D の絵の中で直接クリックしても選べます。

- 行に指を乗せると、3D の絵の中でその形が光ります。どれがどれかを探すときに使えます。
- Shift を押しながらクリックすると、選んだものを増やしたり減らしたりできます。
- いくつも選んでいるときは、右の「プロパティ」に数と種類だけが出ます。

## 数を直す

1 つだけ選ぶと、右の「プロパティ」に入れた値が出ます。**打ち込んだ式がそのまま出ます。**たとえば `10*√2` と入れたところは `10*√2` のまま出るので、`10` の部分だけを `20` に直せます。

直すとその場で形が動きます。その点を使っている線や面も一緒に動きます。

交差した線を途中で曲げたいときは、[交点で線をつなぐ](sketch-intersections.md)を使います。「交点1」をドラッグするか、位置を数値で直すと、共有する区間が一緒に動きます。元の長さ・角度の式は「線分1 始点」「線分1 終点」などに残ります。

正しくない式にすると欄が赤くなります。赤いあいだは形は変わりません。直せば元どおり動きます。

## 位置の決め方を変える

位置の欄の上には「絶対」「相対」「極」の 3 つのボタンがあります。押すと決め方を変えられます。

決め方を変えると欄の意味が変わるので、値は引き継がずに最初の値へ戻ります。変えたあとに入れ直してください。

## 直せるもの

| かいたもの | 直せる値 |
|---|---|
| 点 | 位置(X・Y・Z、またはずれ、または距離と角度) |
| 線分 | 始点と終点 |
| 円弧 | 中心、半径、始まりの角度、終わりの角度 |
| 点列 | 基準の点、向き、間隔、個数 |
| 面 | 色 |

いちばん下には、いまの値から計算した結果(位置・長さ・点の数・三角形の数)が出ます。ここは読むだけで、直接は直せません。

## 消す

モデルブラウザの行に指を乗せると、右端に「⋮」が出ます。押すと開く一覧の「削除」で消えます。行を選んで Delete キーを押しても消えます。

消したものを使っていた線や面は計算できなくなりますが、**アプリは止まりません。**計算できなくなった行には赤い印が出ます。

## 計算できなくなったとき

もとにしていた点を消すなどして計算できなくなると、モデルブラウザのその行に赤い印が出て、下の帯に理由が出ます。赤い印に指を乗せると理由が読めます。値を直すか、選び直してください。

## やり直したいとき

上の「元に戻す」(左向きの矢印)を押すと、直前の操作を取り消せます。「やり直す」(右向きの矢印)で、取り消した操作を戻せます。キーボードでは Ctrl+Z が「元に戻す」、Ctrl+Y が「やり直す」です。戻せるものが無いときは、ボタンが薄く表示されます。
