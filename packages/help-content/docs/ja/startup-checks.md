# 起動しない・3D表示が出ないとき

Web版は、配布案内に記載された場所をブラウザーで開いて使います。アプリ本体のファイルを端末へコピーし、`index.html`だけを直接開く方法では起動できません。通信を切って使う場合は、先に[通信なし利用の準備](offline-use.md)を済ませてください。

## 上のボタンが見え、3D表示だけが出ないとき

「{{ui:viewport.failed}}」と表示されても、編集中の文書は保持しています。

1. 上の「保存」で、先に文書をファイルへ保存します。
2. 3Dを使う他の画面を閉じ、端末の負荷を減らします。ブラウザーのグラフィック設定を変更した場合は、設定内容も確認します。
3. 「{{ui:viewport.retry}}」を押します。画面の表示を作り直し、同じ文書を表示します。
4. 再試行しても表示できない場合は、保存したファイルを残したうえで、ブラウザーまたはデスクトップ版を開き直します。

再読み込みやアプリの終了を先に行うと、最後に保存してからの変更を失うことがあります。まず文書を保存してください。

## 読込みが終わらない・画面全体が開かないとき

| 状態 | 確認すること |
|---|---|
| 初めて開き、読込みが続いている | 初回は計算に必要なファイルも取得します。通信が続いているか確認し、読込みを待ちます |
| 通信を切ると開かない | 通信を戻して開き、設定で通信なし利用が準備完了になっているか確認します |
| 説明書は読めるが作図画面が開かない | 説明書だけを開いていないか確認し、配布案内のアプリへのリンクを開きます |
| コピーしたHTMLファイルだけを開いている | 配布案内のWeb版を開くか、対応するデスクトップ版を使います |
| 特定のブラウザーだけで開かない | 文書を保存した後、対応する別のブラウザーでも同じ公開先を確認します。ブラウザーごとの設定や保存内容は引き継がれません |

ブラウザーの保存内容を消す操作は、自動の控えや通信なし利用の準備も消す場合があります。画面に入れない場合でも、以前に自分で保存した文書ファイルは保管したままにしてください。

## 自分でWeb版を配信する場合

配布用のWebファイルは、通信の扱いを指定した設定と一緒に配信します。画面だけを別の場所へコピーしたり、設定を省いたりすると、計算部や通信なし利用が動かなくなる場合があります。

配信を設定する方は、HTTPSでアプリと計算部を同じ公開先から配り、応答に次の指定を含めてください。

| 応答の項目 | 指定する値 |
|---|---|
| `Cross-Origin-Opener-Policy` | `same-origin` |
| `Cross-Origin-Embedder-Policy` | `require-corp` |
| `Cross-Origin-Resource-Policy` | `same-origin` |

Cloudflare Pages向けの配布物には、これらを含む`_headers`を用意しています。配布物に含まれる他の設定も保ち、利用者にブラウザーの保護機能を切るよう案内しないでください。公開後は、実際の公開先で起動・作図・保存・説明書を確認します。
