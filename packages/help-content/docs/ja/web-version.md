# Web版をブラウザーで使う

Web版は、アプリを導入せずにブラウザーから作図するための版です。部品、組立、図面を同じ画面で扱い、作った文書は端末へファイルとして保存します。

## 公開先と対応する環境

現在は公開準備中で、正式なWeb版の場所はまだ案内していません。公開時に配布案内へ記載するリンクから開いてください。説明書を読めることだけでは、その場所で作図もできるとは限りません。

対応対象はパソコンのChrome、Edge、Firefoxの最新版です。3D表示を使える環境で開き、初めて使う際は通信できる状態にします。ブラウザーのグラフィック設定や端末の制限で3D表示を始められない場合は、[起動しないときの確認](startup-checks.md)を参照してください。

ブラウザーを使わずに端末へ入れて使いたい場合は、[デスクトップ版の導入・更新・削除](desktop-install.md)を参照してください。

## 作図を始めて保存する

1. 配布案内のWeb版へのリンクを開き、上のボタンと作図画面が表示されるまで待ちます。
2. 初めての作図は、[練習の手順](tutorial.md)に沿って点、輪郭、立体を作ります。操作の途中でもF1で説明を開けます。
3. 「保存」を押し、ダウンロードした文書を保管します。保存場所の確認画面が出た場合は、保存先を選んで確定します。
4. 作業を再開するときは「開く」を押し、保存した文書を選びます。別のブラウザーや端末で続ける場合も、文書ファイルを渡して開きます。

保存した文書は、種類に応じて`.pcad`、`.pcada`、`.pcadd`という末尾の名前になります。ブラウザーの保存先設定によって、同じ名前のファイルに番号が付く場合があります。以前の文書を上書きできたと思い込まず、最新の保存結果を確認してください。詳しい操作は[保存と開き方](save-and-open.md)にあります。

## 文書と通信の扱い

形や数式の計算は端末で行います。作図した文書を自動で公開先へ送って保管するサービスではありません。自動の控えや表示設定は使っているブラウザーに残りますが、別のブラウザーには引き継がれません。大事な作業は文書ファイルとして保存してください。

通信を切って使う場合は、先に設定で[通信なし利用の準備](offline-use.md)を済ませます。準備の完了後も、文書の保存は別に必要です。詳しい保存場所と通信の説明は[作図したデータの扱い](local-data.md)を参照してください。
