# 単位を変える(ミリメートルとインチ)

長さの表示を**ミリメートル**と**インチ**で切り替えられます。切り替えると、画面に出る数と、数を打つ欄の両方が変わります。

## 切り替えかた

いちばん下の帯の右のほうに、**mm** と **inch** の切り替えがあります。押すとその場で切り替わります。アプリを起動し直す必要はありません。

選んだ単位はこの端末に覚えられます。次に開いたときも同じ単位で始まります。**部品のファイルの中身は変わりません。** 同じ部品を、ミリメートルの人とインチの人がそれぞれの単位で見られます。

## インチにすると変わるもの

- プロパティに出る長さが `10` から `0.394` のようになります。
- 測った長さ、体積、密度もインチの単位で出ます。
- 重さは g・kg のままです。重さは長さの単位に関係しないためです。

## 欄に単位を書いて打てる

どちらの表示にしていても、数の後ろに単位を書けます。

| 打つ文字 | 入る長さ |
|---|---|
| `2mm` | 2 ミリメートル |
| `1.5in` | 38.1 ミリメートル |
| `1.5"` | 38.1 ミリメートル(`"` はインチと同じ) |
| `3/8"` | 9.525 ミリメートル |
| `1.5 in` | 38.1 ミリメートル(間に空白を入れてもよい) |
| `1.5IN` | 38.1 ミリメートル(大文字でもよい) |

足し算・引き算で単位を混ぜることはできません。`1in + 2` のように片方だけに単位を書くと、「単位をそろえてください。」と出ます。`1in + 2mm` のように両方に書けば計算できます。

かけ算・わり算の相手には単位を書きません。`1in * 2` は 2 インチ(50.8 ミリメートル)です。

フィート(`'`)は使えません。

## 単位を書かずに打ったとき

**表示をインチにしているとき、単位を書かずに打った数はインチとして読まれます。**

- 欄に `1.5` と打つ → 1.5 インチ(38.1 ミリメートル)
- 欄に `10*2` と打つ → 20 インチ(508 ミリメートル)

表示をミリメートルにしているときは、これまでどおりミリメートルとして読まれます。

## 名前を付けた数値を式に使うとき

名前を付けた数値(パラメータ)を式の中で使うときも、**表示している単位の世界で計算されます。**

たとえば `w` が 25.4 ミリメートル(= 1 インチ)のとき、表示をインチにして次のように打つと、

| 打つ文字 | 入る長さ |
|---|---|
| `w*2` | 2 インチ = 50.8 ミリメートル |
| `w/2` | 0.5 インチ = 12.7 ミリメートル |
| `w+10` | 11 インチ = 279.4 ミリメートル |

**`w+10` は表示している単位で答えが変わります。** ミリメートル表示のときは 35.4 ミリメートルですが、インチ表示のときは `1 + 10 = 11` インチになります。「欄に見えている数と同じ単位で打てる」ようにした結果です。

思っていたのと違う数になっていないかは、欄のとなりに出る答えの値で確かめられます。単位をはっきり書いて `w+10mm` と打てば、表示に関係なく 35.4 ミリメートルになります。

## 切り替えても式は書き換わらない

**一度保存した式の文字は、単位を切り替えても 1 文字も変わりません。** ミリメートル表示のときに `10` と打った欄は、インチ表示にしても `10` のままです。欄に出る答えの値だけがインチで表示されます。

その欄を編集して確定したときに、はじめてインチとして入り直します。

## 分数のインチ

インチ表示のときは、長さを `3/8"` のような分数でも出せます。64 分の 1 まで刻んで、いちばん近い分数へ丸め、約分して出します。

- 9.525 ミリメートル → `3/8"`
- 12.7 ミリメートル → `1/2"`
- 25.4 ミリメートル → `1"`

10 ミリメートルのようにちょうどの分数にならない長さは、いちばん近い `25/64"` で出ます。もとの長さとは 0.08 ミリメートルほどずれます。**内部の長さは丸められません。** 表示だけが分数になります。

## 読み込んだファイルの単位

ほかのソフトから取り込んだ形の単位は、この切り替えとは別です。取り込むときにファイルごとに決まります([読み込む](import.md))。

書き出すファイルの単位も、この切り替えとは別です。書き出すファイルはいつもミリメートル(glTF だけメートル)です([書き出す](export.md))。
