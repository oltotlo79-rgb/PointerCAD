# 好きな向きの作業平面を作る

XY・XZ・YZ の 3 面だけでは足りないときは、自分で作業平面を作れます。作った面は「作図面」の一覧に名前で並び、選べばその上に点・線・図形をかけます。

## 作り方を選ぶ

画面の上の「作図面」を押すと一覧が開きます。XY・XZ・YZ と、これまでに作った面の名前が並び、その下に**作業平面を作る…**として 4 つの作り方が出ます。

| 作り方 | 何を決めるか | よく使う場面 |
|---|---|---|
| 作業平面(3 点) | 通したい点を 3 つ入れる | 傾いた面をひとまとめに決めたいとき |
| 作業平面(オフセット) | もとにする面と、そこから離す距離 | 床から 10mm 上の面がほしいとき |
| 作業平面(傾ける) | 傾ける軸と角度 | いまの面を 30 度だけ倒したいとき |
| 作業平面(点を通る) | 通したい点と、辺・面・軸のどれを基準にするか | 立体の辺や面に合わせたいとき |

どれを選んでも、画面の中に小さな入力欄が浮かびます。数値は式でも入れられます(`10+5`、`100/3` など)。Tab で次の欄、Enter で決定、Esc で取消です。

## 3 点で作る

1. 一覧から「作業平面(3 点)」を選びます。
2. 1 点目の位置を入れて Enter。ビューポートをクリックしても、その位置が欄に入ります。
3. 2 点目、3 点目と続けます。2 点目からは「相対」が選ばれていて、1 つ前の点からのずれで入れられます。
4. 3 点目を決めると面ができ、そのまま作図面として選ばれます。

3 点が一直線に並んでいると面が決まりません。そのときは画面の下の帯に「3 点が一直線に並んでいるため、平面が決まりません。」と出ます。3 点目を線から外して入れ直してください。

## 面から離して作る

1. 一覧から「作業平面(オフセット)」を選びます。
2. 「もとにする面」で、いまの作図面・XY・XZ・YZ・選んだ面のどれかを選びます。
3. 「距離」を入れて Enter。

**負の値を入れると反対側へ離れます。** 0 を入れると、もとの面と同じ位置の面になります。

「選んだ面」を使うときは、先に立体の**平らな面**をクリックして選んでおきます。選んでいないと「平らな面を 1 つ選んでから決定してください。」と出て、何も作られません。

## 傾けて作る

1. 一覧から「作業平面(傾ける)」を選びます。
2. 「軸」で X・Y・Z のどれか(または作ってある基準軸)を選びます。
3. 「角度」を入れて Enter。

もとになるのは**いま選ばれている作図面**です。XY を選んだ状態で X 軸まわりに 90 度傾ければ、前から見た面と同じ向きになります。

## 点を通る面を作る

1. 一覧から「作業平面(点を通る)」を選びます。
2. 通したい点の位置を入れて Enter。
3. 「決め方」から選びます。

| 決め方 | 先に選んでおくもの |
|---|---|
| 辺に垂直 | 立体のまっすぐな辺 |
| 辺を含む | 立体のまっすぐな辺 |
| 面に平行 | 立体の平らな面 |
| 軸に垂直 | (何も要りません。軸と角度を欄で入れます) |

「軸に垂直」を選ぶと「傾き」と「倒す向き」の欄が出ます。どちらも 0 のままなら、選んだ軸にまっすぐ垂直な面になります。傾きは 0 度以上 180 度未満です。

## 作った面を使う

- 作った面は「作図面」の一覧に「作業平面1」のような名前で並びます。押せばその面に切り替わります。
- 切り替えると、ビューポートの薄い四角がその面の向きになり、方眼と角度の基準もその面になります。
- その面の上に線や図形をかき、いつもどおり厚みをつけられます。

## うまくいかないときは

平面が決まらないときは、画面の下の帯に理由が日本語で出ます。よくあるものは次のとおりです。

- 「3 点が一直線に並んでいるため、平面が決まりません。」— 3 点目を線から外してください。
- 「平らな面を 1 つ選んでから決定してください。」— 丸みのある面ではなく、平らな面を選んでください。
- 「まっすぐな辺を 1 本選んでから決定してください。」— 円い辺ではなく、まっすぐな辺を選んでください。
- 「…は後から作られたので、参照できません。先に作ってください。」— 基準にしたいものを先に作ってから、平面を作り直してください。

作った面が要らなくなったら、元に戻す(Ctrl+Z)で 1 回押せば消えます。面を決めるために入れた点もいっしょに消えます。
