# 簡易強度計算の材料・ねじ断面積の出典

確認日：2026-09-11。対象：FR-1112、P11b-2・3、計画書§0.a-0.2。

実装の正本は `packages/model/src/measure/strengthMaterials.ts` と `boltStressAreas.ts`。製品条件を含むIDで管理し、外観・密度の材料IDとは別にする。材料の公称降伏点や参考値を、無条件に利用できる「JISの許容応力」とは表示しない。許容応力は指定安全率から計算する。規格全文の確認・最新版の確認と、メーカー公開資料で確認できた抜粋を区別する。

- [日本アルミニウム協会 建材ガイド](https://www.aluminum.or.jp/fields/kenchiku/kenzai/guide/b/)：JIS H 4000の板材の機械的性質表。A5052P-H34の掲載板厚0.2〜1.3mmだけを採る。E・Gは未掲載。

これらの資料から規格の適用版と使用温度範囲を確定できなかったため、データの `standardEdition` はnull、温度は未指定とする。「室温の規格保証値」などの表示をしない。S45CのE・Gは熱処理別に測定された値ではなく、JFEの鋼一般の参考値との組合せである。

## ボルト断面積

公称値の48組（並目28、細目20）を直径・ピッチで引く。M2〜M64の呼び・ピッチは既存 `metricThread.ts` から選ぶ。そこにある全56組のうち、出典で断面積を確認していない8組は公称値で計算させない。

- [ミルコン ボルトの引張有効断面積](https://www.milcon.co.jp/data/pdf/product_2669.pdf)：PDF2頁の「JIS B1082-2009」の表。並目M8〜M64の21組と細目M8〜M39の14組を採用。M10×1.5は58mm²、M36×3は865mm²。
- [ハードロック ねじの構造について](https://navi.hardlock.co.jp/column/%E3%81%AD%E3%81%98%E3%81%AE%E6%A7%8B%E9%80%A0%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6/)：小径の並目7組と大径の細目6組を採用。**M36/M39細目のピッチ表記はミルコン資料と整合しないため、その2行は採用しない。** 面積だけの転記でピッチの相違を見落とさない。
- [SOLIDWORKS公式ヘルプ・Tensile Stress Area of a Bolt](https://help.solidworks.com/2018/english/solidworks/cworks/r_tensile_stress_area_bolt.htm)：`At = π/4 × ((d3+d2)/2)²`、`d3=d−1.2268P`、`d2=d−0.6495P`、簡約された係数0.9382を確認。「近似式」を明示的に選んだ場合だけ `π/4 × (d−0.9382P)²` を計算する。丸められた公称面積をこの式で置換しない。公称値未確認を黙って近似へ切り替えない。

## 採用しなかった補完

- 日本製鉄テクノロジーのSUS304弾性係数は特定寸法試験片の測定値。S008のEと、別の試験片のGを同一条件の規格値として混ぜない。
- Protolabs資料はA5052-H32の代表値で、設計目的に用いない旨もある。H34の欠けた定数を埋めるためには採用しない。
- 別資料で見つけた0.33は熱伝導率の列であり、ポアソン比ではない。`G=E/(2(1+ν))` の根拠にはできない。
- 証明書のホスト名が合わず取得できなかったURLは確認済み出典に数えない。

## 物的な再発防止

材料IDに条件を含め、板厚範囲を計算前に検査する。未掲載弾性定数をnullで保持し、材料切替時に旧値を消す。公称断面積未掲載は失敗を返す。材料値変更の事実を計算結果の入力控えへ記録する。長方形の応力は `6M/(bh²)` で計算し、丸めた `bh²/6` の逆数による不要な端数を避ける。6MPaの境界と、降伏点を1e-30小さくした場合の判定を独立の検査で固定する。
