# 分解した見せ方を作る

離して見せたい部品を左の一覧または画面で選び、上の **分解** を押します。離す向きと距離を入力し、Enterで分解ステップを作ります。Escで取り消します。

分解ステップは左の一覧に残り、組み立ての共通時間軸で動きを確認できます。元の組み立て位置や合致は変わりません。

複数の部品を選ぶと、同じ向きと距離でまとめて離せます。値には式も使えます。

## うまくいかないとき

- **距離の式を計算できません。** … 距離の欄に計算できない式を入れて作ろうとすると出ます。式を直すと作れます。

作った分解ステップは、離す部品・向き・距離が組み立てに保存され、開き直しても残ります。共通時間軸のつまみの位置(いまどれだけ離れて見えるか)は保存されないため、開き直すと0%の位置に戻ります。
