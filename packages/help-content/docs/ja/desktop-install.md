# デスクトップ版の導入・更新・削除

PointerCADのデスクトップ版は、Windows(10・11、64ビット)とLinux(64ビット)向けに配布します。ブラウザーで使うWeb版とは別に、端末へ入れて使う版です。この章では、入手できる形式ごとの導入・更新・削除の手順と、未署名の配布物を確認する方法をまとめます。

## 入手できる形式

| OS | 形式 | 導入の操作 | 管理者権限 |
|---|---|---|---|
| Windows 10・11(64ビット) | インストーラー版(`PointerCAD-<版>-windows-x64-setup.exe`) | 必要 | 不要(今使っているアカウントだけに導入します) |
| Windows 10・11(64ビット) | ポータブル版(`PointerCAD-<版>-windows-x64-portable.exe`。1つの実行ファイル) | 不要 | 不要 |
| Linux(64ビット) | AppImage(`PointerCAD-<版>-linux-x64.AppImage`。1つの実行ファイル) | 不要 | 不要 |

## Windows:インストーラー版を導入する

1. 配布ページから、`PointerCAD-<版>-windows-x64-setup.exe`という名前のインストーラーをダウンロードします。
2. ダウンロードしたファイルを実行し、案内に沿って進めます。導入先のフォルダーは変更できます。
3. 完了すると、スタートメニューにPointerCADが登録されます。デスクトップへのショートカットは作られません。
4. 導入の直後にアプリは自動では起動しません。スタートメニューから開いてください。

## Windows:ポータブル版を使う

1. 配布ページから、`PointerCAD-<版>-windows-x64-portable.exe`という名前のファイルをダウンロードします。
2. ダウンロードしたファイルをそのまま実行します。導入の操作は要りません。
3. 起動のたびに、実行に必要な内容を一時的な場所へ取り出してから開きます。終了すると取り出した内容は片付けます。
4. 設定や保存した文書は、この実行ファイルの場所とは別に管理します。ファイルを削除しても、それらは残ります。

## Linux:AppImageを使う

1. 配布ページから、`PointerCAD-<版>-linux-x64.AppImage`という名前のファイルをダウンロードします。
2. ファイルに実行の許可を与えます。ファイルマネージャーの「プロパティ」から「実行を許可する」のような項目を選ぶか、ターミナルで`chmod +x <ダウンロードしたファイルのパス>`を実行します。
3. 許可を与えたファイルをそのまま実行します(ダブルクリック、またはターミナルで`./PointerCAD-<版>-linux-x64.AppImage`)。導入の操作は要りません。ファイルマネージャーでの表示や実行の許可の与え方は、使っているデスクトップ環境によって異なります。

## 正式な入手元と、未署名の配布物への警告・確認方法

### 正式な入手元

PointerCADの配布物は、GitHubの本プロジェクトのリリースページ(`https://github.com/<所有者>/<リポジトリ名>/releases`。実際のURLはREADMEと本書の入手方法の章に掲載します)からだけ配布します。他の場所で見つけたPointerCADと称するファイルは、内容を保証できないため使わないでください。

### 未署名であることと、Windowsの警告の出方・進め方

配布するWindows・Linuxの実行ファイルには、今のところ発行元の署名がありません。これは、ファイルの作成元をOSが電子的に確認できる仕組み(コード署名)を、まだ導入していないという意味です。

Windowsでインストーラー版・ポータブル版を実行すると、「Windows によって PC が保護されました」という青い画面(SmartScreen)が表示されることがあります。これは発行元が確認できない実行ファイルに対してWindowsが表示する標準の警告で、PointerCAD固有の異常ではありません。実行を続ける場合は、次の手順で進めます。

1. 表示された画面の中の「詳細情報」(または「More info」)を選びます。
2. 発行元に「不明な発行元」のような表示のまま、ファイル名と「実行」ボタンが表示されるので、入手元が上記の正式なリリースページであることを確認したうえで「実行」を選びます。

この警告が出るかどうか、文言や画面の見た目は、Windowsの版や設定によって変わることがあります。案内をよく読み、入手元に確信が持てない場合は実行を中止してください。

### ダウンロードしたファイルが正しいことの確認(ハッシュの照合)

配布ページには、配布する各ファイルのSHA-256という値の一覧を`SHA256SUMS`という名前のテキストファイルで添えます(ファイル名と値の組を1行ずつ並べたものです)。ダウンロードしたファイルからも同じ方法でSHA-256の値を求め、この一覧の値と比べることで、ダウンロードの途中で壊れていないか、配布時点から内容が変わっていないかを確認できます。値が異なる場合は、そのファイルを実行せず、配布ページから取得し直してください。

| OS | SHA-256の値を求める方法 |
|---|---|
| Windows | PowerShellで`Get-FileHash <ファイルのパス> -Algorithm SHA256`を実行します |
| Linux | ターミナルで`sha256sum <ファイルのパス>`を実行します |

この値の一致が確認できるのは、ファイルの中身が配布時点のものと変わっていないことだけです。ファイルの作成元がPointerCADの開発元であることまでを電子的に証明するものではない(それには前述のコード署名が要る)点に注意してください。

## 更新する

新しい版は、配布ページから改めてダウンロードして導入し直します。アプリ内やOSからの自動更新の通知はありません。

インストーラー版を更新するときは、新しいインストーラーを実行すると、今の導入先へ上書きして更新します。実行しようとした時点でPointerCADが起動していると、文書を保存してアプリを終了するよう案内が表示され、終了を確認できるまで更新を続けません。

ポータブル版・AppImageを更新するときは、新しいファイルをダウンロードし、前のファイルと置き換えて使います。起動中のまま置き換えないよう、先に終了してください。

## 削除する

### Windows(インストーラー版)

Windowsの「アプリと機能」(または「プログラムのアンインストール」)からPointerCADを選び、アンインストールします。PointerCADが起動している場合は、文書を保存してアプリを終了するよう案内が表示され、終了を確認できるまで削除を続けません。

削除するのは、導入時に配置したプログラムのファイルだけです。保存した部品・組立・図面のファイルや、自動で残した控え、設定は削除しません。途中でファイルを戻せなかった場合は、その旨と控え先を示して中断します。

### Windows(ポータブル版)・Linux(AppImage)

ポータブル版とAppImageには削除の操作がありません。ダウンロードしたファイルを削除するだけで取り除けます。設定や自動で残した控えはファイルとは別の場所で管理しているため、削除しても残ります。まとめて消したい場合は、保存場所を自分で確認してください。

## 必要な環境

Windows 10・11(64ビット)、またはLinux(64ビット)で使えます。導入と更新の際にファイルを取得するために通信を使います。導入後の起動や作図に通信は要りません。

3D表示が始まらない場合は、[起動しないときの確認](startup-checks.md)を参照してください。
